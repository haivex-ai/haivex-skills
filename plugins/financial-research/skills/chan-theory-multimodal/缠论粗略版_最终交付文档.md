## 一、系统定位

本系统定位为"粗略版"缠论实战系统，**不依赖严格递归中枢体系**（分型→笔→线段→中枢→走势类型递归），而是将缠论原文中的三套独立子系统组合成可编程的综合决策系统：

| 替代方案       | 原文概念            | 原因               |
| ---------- | --------------- | ---------------- |
| 5/10均线湿吻区域 | 中枢              | 不实现递归中枢构建        |
| 盘整背驰       | 趋势背驰（a+A+b+B+c） | v2.0 修正版删除标准趋势背驰 |

## 三、系统架构与数据流

```
输入: 原始K线序列 (List)
│
├─ STEP 1: kline_processing.py
│     process_inclusion() → List
│
├─ STEP 2: ma_system.py ─────────────────────┐
│     calc_ma() → 体位 + 吻分类 + 缠绕次数      │
│                                             │
├─ STEP 3: fractal_detector.py ──────────────┤
│     detect_all_fractals() → 分型方向+强度     ├─ 并行计算
│                                             │
├─ STEP 4: macd_analyzer.py ─────────────────┘
│     compute_macd() → DIF/DEA/柱 + 盘整背驰
│
├─ 辅助模块（按需调用）
│     multi_period.py        → 多周期联立确认
│     surface_relation.py    → 表里关系状态机
│     same_level_decomposition.py → 同级别分解
│     bollinger_zhongyin.py  → 中阴+布林辅助
│     divergence_checker.py  → 三法综合背驰评分
│     sector_rotation.py     → 板块轮动方向
│     position_manager.py    → 仓位+成本归零
│     boundary_handler.py    → 陷阱检查+边界条件
│
└─ STEP 5: main_analyzer.py
      analyze_stock() → TradeSignal
      
      决策矩阵：
        ma_state  fractal_state  macd_state  →  决策
        ───────────────────────────────────────────
        男上位    底分型+强       背驰        →  buy_1 (高置信)
        女上位    底分型+弱       未背驰      →  hold (观望)
        女上位    顶分型+强       背驰        →  sell_1 (高置信)
        女上位    第1次缠绕       回抽0轴     →  buy_2 (中置信)
        男上位    顶分型+强       未背驰      →  hold (持币)
```

## 四、核心算法摘要

### 4.1 K线包含处理（§3）

- 方向向上(1)：取 `max(high)`, `max(low)`
- 方向向下(-1)：取 `min(high)`, `min(low)`
- 方向未定(0)：默认按向上处理

### 4.2 吻分类（§4.3，可配置阈值）

- 飞吻：`KISS_WET_RATIO < gap_ratio ≤ KISS_FLY_RATIO`，3-5根趋势不变
- 唇吻：`gap_ratio ≤ KISS_LIP_RATIO`，触及但未穿越
- 湿吻：发生交叉（短期均线穿越长期均线）

### 4.3 分型强弱三档（§5.2）

- 顶分型·最强：k3跌破k1底且收不到k1区间一半之上 → 几乎100%成笔
- 顶分型·较强：k2长上影/长阴 + k3收不到k2区间一半之上
- 顶分型·中继：k1长阳 + k2、k3小阴小阳 → 成笔概率极小
- 底分型完全对称

### 4.4 MACD盘整背驰（§7.2）

- 同向两段A和C：比较MACD柱子面积
- `area_ratio = segment_C.area / segment_A.area`
- `area_ratio < DIVERGENCE_AREA_RATIO(0.9)` → 盘整背驰成立

### 4.5 综合背驰三法评分（§11.4）

- ≥2种方法确认 → "背驰确认"
- 1 种方法确认 → "疑似背驰"
- 0 种方法确认 → "无背驰"

### 4.6 表里关系四态（§8.2）

- (1,1) 向上笔延伸中 → (1,0) → (1,1) 延续 或 (-1,1) 转折
- (-1,1) 向下笔延伸中 → (-1,0) → (-1,1) 延续 或 (1,1) 转折

## 七、使用示例

```python
from scripts.main_analyzer import analyze_stock
from scripts.data_structures import KLine

# 1. 准备K线数据
klines = [
    KLine(time=..., open=..., high=..., low=..., close=..., volume=...),
    ...
]

# 2. 全流程分析
signal = analyze_stock(klines)

# 3. 查看决策
print(f"信号: {signal.signal_type}")
print(f"置信度: {signal.confidence}")
print(f"建议仓位: {signal.position_size}")
print(f"说明: {signal.description}")

# 4. 多级别联立
from scripts.multi_period import multi_period_decision
ok, msg = multi_period_decision(
    h_direction=1,      # 周线多头
    m_signal_type="buy", # 日线买点
    l_confirmed=True,    # 30分钟区间套确认
)
```
