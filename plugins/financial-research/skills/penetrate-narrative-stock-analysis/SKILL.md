# 穿透叙事

## 框架总览

核心命题：**超额收益只能来自叙事变化**；如期兑现叙事只带来约等于折现率的必要收益。

「叙事」= 市场对公司**终局稳态业绩高度 L** 的可量化共识。默认只做两件事：

1. **反算**：当下股价（及各券商目标价）各自隐含的 L 是多少；
2. **列示**：市场各方（一致预期、内外资券商、纪要/点评中的多空）对终局与路径怎么说，分歧落在哪些可量化变量上。
3. 当用户输入多家公司时，自动结合最新财报和管理层电话会，列表汇总盈利预测，并计算L/E0、L/E3，然后对每家公司的财报现实、股价隐含叙事以及最新边际变化进行展开。

### 多家公司隐含叙事一致性

当用户提问到多家公司隐含叙事一致性时，逐个计算公司隐含叙事，对比利润走势以及比例关系，不要引入利润率假设反算收入。叙事自洽性判断标准是，如果供应链企业的远期空间低于下游客户远期空间，隐含市场份额被稀释或者利润率降低的预期，可以被合理解释，反之亦然。只有多家竞争对手的市场份额合计大于100%，或者类似上下游产业链隐含利润率同时大幅上升，且没有强需求侧逻辑做解释，才是不自洽。适当放宽标准，只要能够被一套更大的叙事完整解释，就是自洽。

**路由（HARD）**：

1. **仅分析叙事/隐含 L/出报告**（未提复盘）→ 默认深度报告：反算 + 券商专节 + 边际/信号 + 客观收束；**禁止**读 `retrospective-module.md` / `retrospective-long-span-prompt.md` / `retrospective-short-window-prompt.md`；**禁止**写「过去一年/半年叙事复盘」专章、对宽基超额切段、复盘五问、叙事阶段表；可用 1–2 句概述最近市场关注点，不得展开行情复盘。核心结论可提示「若需行情/叙事复盘可显式追问」（可选，不强推）。
2. **命中复盘专项话术**（复盘/行情复盘/超额收益复盘/阶段叙事/逐日复盘等）→ **先读** `references/retrospective-module.md` 与 `references/case-studies.md`，走复盘五步；若标的**深度绑定海外产业链**且复盘窗内有大幅波动，须遵守该模块 **§2.4 双市场检索**（海外上下游 + 跨市场共振，禁止只归因国内宏观）；**不要**默认展开完整「当下隐含 L + 全量券商目标价」深度报告（除非用户同时要求「分析+复盘」）。**长跨度（>7 日）成文**：取数作图后，严格采用 `references/retrospective-long-span-prompt.md` 的结构并用 `write_file` 成文。**短窗（≤7 日）成文**：取数 + **`dcf_implied.py` 水位**后，结构 **必须**采用 `references/retrospective-short-window-prompt.md`（中际旭创样板），并用 `write_file` 成文；**禁止**跳过第〇章绝对水位直接逐日归因。
3. **同时要求分析+复盘**：先完成默认客观列示报告（仍不内嵌复盘章），再按复盘模块另出独立复盘 md；或用户明确要合并时在默认报告外追加复盘专章并标明「应复盘请求生成」。

同源铁律：对话与报告的 **DCF 数字、券商隐含 L、阵营归纳**必须一致；差别只在详略。默认与增补共用同一套市值/E1–E3/股本口径。

对话问「贵不贵」但未要结论时：只输出现价隐含 L 与主要券商目标价隐含 L 的对照，**不**给贵贱结论，结尾可提示可出正式报告或可追问情景/建议。

详规见 `references/data-collection.md`。三路并行落盘 `tmp/{session_id}/`：

- 口径（选连续3年E1/E2/E3、单位换算、consensus排序、总股本补齐）由脚本固化，**不再现场判断**，装配后自动自检（cap≈价×股本）。

2. **语义穷举**（`doc_searcher`）：公告12个月、纪要/研报/点评近6个月 → `01_ann`/`02_roadshow`/`03_report`/`04_comment`；四类**可拆并行委托提速**，研报单路强制 `stock.code` 精确过滤；`search_paipai` 可选补充

4. **关键词热度取数**：`doc_searcher` 拉取过去约 12 个月、公司相关的研报/纪要/点评/社媒/基金观点（多源、按月分片穷举）→ `tool_outputs/*.json`；由 `scripts/keyword_heat.py` 计算热度（详规见 `references/keyword-heat-module.md`）

注意：默认模式下，收集行业 TAM/份额/净利率是为**还原市场如何讨论终局**（报告正文**不再**写等价反推专节），**不是**为本方构造理论区间。若后续进入追问增补，可复用同一批材料构造情景，不必为情景单独重做第零步（缺关键 TAM/份额/利润率数据时再补搜）。

检查清单：有市值+E1/E2/E3；四类语义有检索记录；内外资强制券商清单已检索；有目标价与无目标价两类材料已分流；材料均已落盘。

## 分析工作流

### 第一步：反算当下股价隐含的天花板 L（核心）

调用 `scripts/dcf_implied.py`：

- 输入：市值（亿元）、E1/E2/E3 一致预期归母净利润（亿元；注意万元÷10000）
- r = 8% / 10% / 12%
- 前3年用一致预期；第4年至稳态年（默认2035）从 E3 等比增至 L；此后 g=0 永续
- 输出：各档隐含 L、L/E3、L/E0、g、动态 PE；脚本含反向验证

**一致预期滞后**：须核对最新业绩预告/快报/季报；若 E1 明显落后已披露业绩，**并列**披露主口径与校正口径反算，不二选一「权威化」。

**描述性解读（允许）**：用 L/E3 分级表说明市场隐含增长强度。（默认模式**不再输出**「隐含 L = TAM×份额×净利率」的等价反推专节；若用户追问情景/理论空间，再在增补模式中拆解，且**禁止**标注「可达/不可达」。）

**禁止（默认）**：对照「本报告理论 L」、高估低估、透支结论。

紧接独立章节——**券商观点专节（分两个小节）**：

**搜索范围（强制）**：须主动搜索下列机构对该公司的覆盖/目标价/盈利预测（有则录、无则在报告中声明未检索到）—

- **外资**：高盛 Goldman Sachs、摩根士丹利 Morgan Stanley、瑞银 UBS、花旗 Citi、摩根大通 JPMorgan、汇丰 HSBC、瑞杰 Raymond James、伯恩斯坦 Bernstein、Barclays
- **内资**：中金、中信、国君（国泰君安）、华泰、招商、天风、长江、华源、兴业、华创、国盛、中信建投、开源、中泰

**小节 A·有目标价的券商**（一律 DCF 反算）：

1. 表格逐家：机构、内外资、日期、评级、目标价、市值=价×股本、**DCF 隐含 L（三档或至少 r=10% 中枢）**、L/E3、L/E0、相对现价隐含 L 的倍数差
2. **逐家展开**：用 DCF 语言说明其目标价对应何种终局 L，相对现价更乐观或更保守（**比较数字，不判对错**）
3. 客观归纳乐观阵营 vs 保守阵营：各自目标价区间、隐含 L 区间、常用盈利预测与逻辑关键词
4. **禁止**：用券商原文 PE 目标「重算合理价」替代 DCF；禁止「本报告采信某某」

**小节 B·无目标价的券商**（大部分内资常见）：

1. **表格列示**：机构、日期、评级（若有）、未来三年盈利预测（E1/E2/E3 或其原文口径）、主要观点/关键假设摘要
2. **文字汇总**：按乐观/中性/保守阵营归纳分析其路径假设与关键分歧（不做 DCF 反算，不判对错）

`dcf_implied.py brokers` 仅对「有目标价」小节运行。

### 第二步：叙事行情复盘（**仅用户显式要求复盘时**；默认分析**跳过**）

**HARD**：用户只问「分析某公司叙事」时，**整步跳过**——不读复盘模块、不取历史行情对宽基对照、不写复盘章。直接进入「第三步」。

**仅当**命中复盘话术（见上表「叙事行情复盘（专项）」）时：

1. **必读** `references/retrospective-module.md`（两套模板、五步工作流、工具路径、报告目录）与 `references/case-studies.md`；
2. 长跨度（>7 日）成文 instruction **必须**采用 `references/retrospective-long-span-prompt.md`；
3. 按复盘模块独立成文（**不强制** DCF Excel）；若用户同时要求「分析+复盘」，复盘为**独立产出**或标明「应复盘请求追加」的专章，**不得**默认塞进深度客观列示报告主结构。

要点备忘（仅复盘路径）：

- 对标：主板≈沪深300；创业板/科创板≈创业板指；多起点累计收益，**叙事时段**切分而非自然季年
- 与宽基大致重合→**兑现叙事**；持续跑赢→L 上修；持续跑输→L 下修；急涨急跌后快速回归→**交易性/传闻**，勿强行基本面
- 变化起点：用**当时**盈利预测 + `dcf_implied.py` 反算隐含 L；信息集截止时点，关闭后视镜
- 五问：旧叙事 → 为何被修正 → 新叙事变量 → 诱发因素 → 形成标志；事后再评价兑现/修正；末节产业规律
- 变化尽量落到市场空间/份额/利润率或第二曲线

- 「后续可能被定价的检验信号」清单（中性，不写建议仓位）
- 最新边际变化补充

### 第四步：收束（默认=客观摘要；追问才扩展）

**默认模式必须包含且仅客观：**

1. 现价隐含 L（三档 r）及 L/E0、L/E3
2. 主要券商目标价隐含 L 分布与相对现价的离散度
3. 乐观 vs 保守阵营在关键变量上的表述对照
4. 最新边际变化摘要 + 市场讨论的观察信号（**不含**历史行情复盘阶段表，除非用户本轮要求了复盘）
5. **不给出**理论区间位置关系、高估低估、买卖建议；免责声明保留
6. **必备两处同一句提示**：在「核心结论」最后一段与正文最后（附录前）各写一句—「默认模式不含本方情景与买卖建议。如需情景分档或投资建议框架，可明确追问」

**追问增补模式**：见下一节与 `references/optional-scenario-advice.md`（追问时必读）。

## 追问增补：情景分析与投资建议（可选，默认关闭）

仅当用户明确要求时启用。完整步骤、表格模板与表述规范见 `references/optional-scenario-advice.md`。

要点：

1. **先复用**已落盘的财务、目标价、行业 TAM/份额/利润率材料；缺则补搜，不推翻默认报告的客观数字。
2. **本方情景表**（通常四档：保守/基准/乐观/极乐观或按行业改名）：每档给出可审计的 `L = TAM × 份额 × 净利率`（或周期股标准化利润路径），列明假设来源（公告产能、第三方空间、券商区间上下沿等）。
3. 用 `dcf_implied.py calc` 将各档 L 正算为市值（及对应股价）；用 `verify_L_vs_scenario` 逻辑核对现价隐含 L、券商隐含 L 落在哪一档附近。（**敏感性分析模块已取消**：折现率敏感性由 L/E3 描述性分级表承载，不再单列敏感性专节。）
4. **位置关系**（仅增补）：描述现价隐含 L 相对本方情景区间的位置（下方/内侧下沿/中枢/上沿/上方），可用「相对本方情景偏乐观/偏保守定价」等表述；须同时披露情景假设不确定性，禁止伪装成唯一真理。
5. **投资建议框架**（仅增补且用户明确要建议时）：给检验信号触发的条件化框架（何种信号对应关注/等待/减风险等），避免喊单式「立即买入/清仓」；必须附「不构成投资建议、需独立决策」免责。
6. **交付形态**：优先独立文件 `{公司}_穿透叙事_情景与建议增补.md`，或在原报告末追加「增补章节」并标明「应追问生成」；**不要**静默改写默认核心结论段，把客观列示改成决策文。

## 报告结构（深度默认）

0. **报告最前面（核心结论之前）·「口径、方法与机构搜索范围声明」**：一段声明，含①**数据口径**（分析基准日与最近已收盘交易日、货币与单位、价格/股本口径、E0 与 E1–E3 口径及一致预期日期、已披露中报进度并列说明）；②**方法**（统一 DCF 反算框架：基准年/稳态年/过渡期设定/r 三档/永续假设，L/E3 与 L/E0 定义，券商目标价一律同框架反算，关键词热度的分母分子与 Z 分定义）；③**机构搜索范围**（列出主动检索过的外资与内资机构，并声明哪些未检索到可复核目标价）。
1. **核心结论（客观，≥5 条独立段）**：①现价隐含 L；②券商目标价 DCF 隐含 L 分布（有目标价）与无目标价券商观点摘要；③乐观/保守核心分歧；④最新边际与市场关注点（**非**历史复盘）；⑤观察信号。**不写**「过去一年叙事变化摘要」（除非本轮显式要求复盘）。不写决策建议条。**最后一段必写**：「默认模式不含本方情景与买卖建议。如需情景分档或投资建议框架，可明确追问」。
2. 基础信息
3. DCF 反算（输入参数表、反算结果表、L/E3 描述性分级表、盈利周期事实表；**不再单列敏感性专节**——折现率敏感性由 L/E3 分级表承载）
4. **券商观点专节（两小节，深度档合计≥1100 字）**：先声明搜索过的内外资机构范围；**小节 A·有目标价**（DCF 反算隐含 L + 逐家展开 + 阵营归纳）；**小节 B·无目标价**（未来三年盈利预测表 + 主要观点列示 + 文字阵营汇总）
5. **（默认删除）**过去半年/一年叙事复盘——仅用户显式要求复盘时按 `retrospective-module.md` 另出或追加
6. 信号验证清单与边际变化补充
   6b. **关键词市场热度（默认必做小节）**：详细复合叙事标签（10–14 个，非单词简称）+ 过去一年月度渗透率热力图（绝对值）+ 近1月相对历史 Z 分排序图（边际）；配标签表、排序表与上修/稳态/回落三簇文字（见 `references/keyword-heat-module.md`）
7. **客观收束（必备，须成表）**：**必须**输出一张两列收束表——左列「当前客观事实」、右列「市场分歧核心」，逐维度覆盖股价市值、近端盈利、指引、一致预期、现价隐含 L、券商共识 L、以及 2–3 个关键叙事变量（如行业景气/第二曲线/Capex/份额）；表后配文字解读。**不得**折叠成纯段落，**不得**含高估低估列或操作建议列。
8. **正文最后提示（必备，附录之前）**：再写一句「默认模式不含本方情景与买卖建议。如需情景分档或投资建议框架，可明确追问」（与核心结论尾句相同）。默认报告**不再输出「等价反推专节」**。
9. 附录：数据口径时点（概括、无来源清单）
10. **（仅追问）** 增补：本方情景表 + 位置关系 +（若要）建议框架——见 optional 规格

**来源展示**：对外交付全文不出现 source 数字标记/加密来源标记/文末来源清单；券商**机构名与报告日**作为分析对象可写。  
**禁止 Mermaid**；除「关键词市场热度」小节的两张热度图外不插图（该两图由 `keyword_heat.py` 生成并嵌入）。表格须有文字解读。篇幅：深度约≥1 万字信息量（不含增补亦可独立成篇）。  
**报告必须附 Excel DCF 工作簿**（`build_dcf_workbook.py` 生成；黄格可改 E/L/r/稳态年；与 md 数字同源）。当同时询问多家公司时，不用生成每家公司的excel工作簿。 询问一家公司时，必须附 Excel DCF 工作簿。

完整写作规格见 `references/report-spec.md`（必读后成文）。追问增补规格见同文件「五、追问增补」与 `optional-scenario-advice.md`。Excel 三表字段与自检见 `references/dcf-workbook.md`。
