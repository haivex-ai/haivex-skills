# 叙事短窗复盘 · 成文模板（终稿反向固化）

> **来源**：由终稿样板《中际旭创_叙事短窗复盘_20260911_20260918》反向固化（用户 2026-09-18 确认作为 skill 模板）。  
> **何时使用**：复盘窗口 **≤7 个自然日**，或用户明确「这一周 / 逐日 / 短窗复盘」。与 `retrospective-module.md` **模板 B**、五步工作流配套。  
> **使用**：完成取数 + **强制 DCF 水位** + 逐日信息集后，按本文结构写作并用 `write_file` 输出 md。
> **禁止**：未算隐含 L 就写逐日归因；把单日涨停/跌停升格为重大 L 台阶；默认模式给买卖建议；用 PE 倍数另套估值替代 `dcf_implied.py`。

## 一、占位符（成文前填实）

| 占位符 | 含义 |
|--------|------|
| `{公司}` `{代码}` | 简称与标准化代码 |
| `{起点}` `{终点}` | 窗口起止 YYYY-MM-DD（止日默认最新已收盘；未入库日注明分时/快照口径） |
| `{宽基}` | 创业板/科创→创业板指；主板→沪深300；港/美按 module 声明 |
| `{E0}` `{E1}` `{E2}` `{E3}` | 亿元；E1–E3 为窗口可得一致预期（标注截止日）；E0 优先年报归母，否则 PE-LYR 反推并标注 |
| `{base_year}` `{steady_year}` | 默认 base=报告语境基准年，steady=2035 |
| `{shares}` | 总股本（亿股），与市值/价格同源 |
| `{证据包}` | 日线 csv、DCF 输出、公告/纪要检索摘要路径 |

## 二、成文前强制产物（不可跳过）

### 2.1 行情与日历

1. `trading_calendar`（对应市场）确定窗口交易日；注明 T 日线是否已入库。  
2. `data_analyst`：个股前复权日收 + 宽基日收；算日涨跌、日超额、累计、可选起点归一化。落盘 `retro_prices` csv。  
3. 对标规则见 `retrospective-module.md` §2.1。

### 2.2 叙事绝对水位（HARD · 开篇数字来源）

1. 取窗口末（及事件日高点、周内低点等关键时点）**价格 × 股本 = 市值**。  
2. `python skills/user/penetrate-narrative-stock-analysis/scripts/dcf_implied.py implied`  
   - 输入：`--cap` `--e1` `--e2` `--e3` `--base-year` `--steady-year`  
   - 输出：r=8%/10%/12% 隐含 L、L/E3、隐含 g、动态 PE(E1)；保留反向验证通过记录。  
3. 有 E0 时手算或表列 **L/E0（r=10%）**、**E3/E0**。  
4. 窗口内若热议目标价/评级价：同一 E1–E3、同一股本，`dcf_implied.py brokers` 做 **舆论带宽**（现价 vs 低/中/高目标），**不**采信某一家为真理。  
5. **纪律句**（必须写进报告第〇章导语）：短周期涨跌可能主要不是「本周新边际」，而是 **既有叙事水位偏高/偏低** 时对折现率、拥挤筹码、事件概率的再定价；未先量水位，禁止把高位震荡写成「基本面一日变天」。

### 2.3 信息集（关闭后视镜）

- `search_paipai` / 必要时 `doc_searcher`：窗口内公告、点评、纪要、研报；`end_time` ≤ 讨论日。  
- `search_web`：政策/突发仅作线索，关键事实回锚公告或权威披露。  
- 逐日「当日可知」只写截止当日信息；事后检验单独成小节。

## 三、报告文件名与元信息

`{公司}_叙事短窗复盘_{起点}_{终点}.md`

文首必含：

- **窗口**、**对标宽基**、**框架**一行（写明：先定叙事绝对水位，再解释涨跌是否来自边际/交易）  
- **DCF 口径一行**：脚本名、r 三档、base/steady、E1–E3 对应财年、股本来源  

**禁止 Mermaid / 配图强制**（短窗以表为主；用户未要求不作图）。  
**不强制** Excel DCF 工作簿（与长窗/深度分析报告区分）。

## 四、章节结构（顺序 HARD · 对齐中际旭创样板）

### 文首元信息
（见上）

### 〇、叙事绝对水位（DCF 反算 · 短窗强制前置）

1. **方法纪律**引用块（§2.2 纪律句）。  
2. **0.1 近端盈利路径表**  

| 口径 | 数值 | 备注 |
|------|------|------|
| E0 | | 年报或 PE-LYR 近似（须标注） |
| E1 / E2 / E3 | | 一致预期截止日 |
| E3/E0 | | 近端路径陡峭度 |
| PE-TTM / 动态 PE(E1) | | 两口径勿混 |

文后 **水位含义** 一段：区分「近端 E 路径高」vs「L/E3 是否极端」。

3. **0.2 窗口关键时点：市值 → 隐含 L 表**  

| 时点 | 价格 | 市值 | r=8% L | r=10% L | r=12% L | L/E3(10%) | L/E0(10%) |

至少含：窗口末收盘、窗口内事件高点或用户关心时点、可选周内低点。  
注明反向验证。  
**读数三条**（描述标签，非贵贱）：  
- r=10% 中枢 L 与 L/E3、隐含 g 量级；  
- 周内 ΔL 与股价变动是否同量级（是否「台阶迁移」）；  
- **优先解释框架**：水位内再定价 vs E 路径证伪 vs L 台阶。

4. **0.3 目标价隐含 L 舆论带宽**（有则必做；无则声明未检索到热议目标价）  

| 场景 | 目标价 | 市值 | r=10% L | L/E3 |

带宽含义：日振幅是否落在带宽内博弈，勿把单日涨跌写成全市场切换到某一极 L。

5. **0.4 水位结论 → 如何解释本窗涨跌**（四问表）  

| 问题 | 本窗答案 |
|------|----------|
| 叙事绝对水位高不高？（分近端路径 vs L/E3） | |
| 下跌/震荡是否来自新的利空边际？ | |
| 上涨是否 L 上修/可持续台阶？ | |
| 全窗净结果（价与隐含 L） | |

### 一、窗口结论（主导力量）

表列：主导力量、绝对水位摘要、全窗价格、相对宽基、信息主轴、事后标签。  
**一句话**收束（须点明「水位内波动」或「边际驱动」或「L 台阶」三者之一为主）。

### 二、逐日表（交易日 · 个股 vs 宽基）

| 日期 | 个股收盘 | 个股% | 宽基 | 指数% | 日超额 | 标签 | 当日可知信息（截止当日） |

标签枚举：兑现贴指数 / 事件脉冲 / 脉冲回吐 / 高水位博弈 / 板块 beta / 纯宏观 / 交易性 / 修复 等。  
休市日可一行合并。  
未入库日：* 标注快照口径，不做严格超额或注明局限。

**区间累计表**：个股%、宽基%、超额、并入末日快照（若有）、**隐含 L(r=10%) 起讫 Δ**。  

**脉冲形状表**（可选，多起点累计超额）：用于识别尖峰后回归。

### 三、五问压缩（仅针对窗内主脉冲/主段 · 结合水位）

1. 旧叙事（含脉冲前隐含 L 量级）  
2. 为何被修正（截止拐点日公开信息）  
3. 新叙事变量（风险概率/置信 vs TAM×份额×利润率）  
4. 诱发与价格对齐  
5. 是否站稳（回撤/跑输 → 常为脉冲结束）

**事后检验表**：脉冲对 L 台阶是否有效；高水位解释力；板块 beta 等。

### 四、机制规律（≥5 条，带本窗数字）

样板级要点（可改写，勿空洞清单）：

1. 短窗须先量水位；  
2. 近端路径高 ≠ L/E3 极端（两套尺子）；  
3. 目标价 L 带宽 ≫ 周涨跌时，日波动可为带宽内博弈；  
4. 事件溢价半衰期；  
5. 业绩验证 ≠ alpha；  
6. 尖峰后回归 = 交易性，勿升格长周期 L 上修。

### 五、后续观察信号（中性清单）

表：信号 | 与水位/E 路径/L 的关系。  
**禁止**仓位与买卖语句。

### 六、数据与口径附录

DCF 命令与参数、行情文件、一致预期时点、目标价来源声明、不提供投资建议、不附 workbook 默认。

### 免责声明

公开信息客观列示，不构成投资建议；短窗与未入库数据敏感。

## 五、标签与归因对照（写作时自检）

| 观察 | 优先归因 | 禁止写成 |
|------|----------|----------|
| 价跌但 E1–E3 未下修、ΔL 与涨跌同量级窄幅 | **高/低水位再定价**、筹码、事件溢价 | 「基本面崩了」「L 台阶坍塌」 |
| 单日大涨后数日回吐超额 | **交易性/事件脉冲** | 「新叙事已定盘」 |
| 与同业齐涨齐跌 | **板块 beta** | 独立 alpha / 公司独家终局改写 |
| 与宽基几乎重合 | **兑现/贴指数** | 叙事上修 |
| 目标价 L 差数倍、现价居中 | **终局分歧带宽** | 采信单一目标价解释每日涨跌 |
