# 穿透叙事报告产出规格（客观列示版 + 可选追问增补）

> 写作时必须遵循本规格对应章节。
> **默认**遵循「一、REPORT_SPEC」；否则产出会擅自恢复「理论区间/高估低估/决策建议」。
> **仅当用户明确追问**情景/理论区间/投资建议时，另加「五、追问增补规格」，或在原报告外单独生成增补文件。
> **叙事行情复盘**仅当用户**显式**要求复盘时启用；长跨度 >7 日不要用本章默认 `REPORT_SPEC`，改用 `retrospective-long-span-prompt.md` 第三节 + `retrospective-module.md` 五步约束。
> **默认「分析叙事/出报告」禁止**嵌入复盘章节，禁止读复盘模块，禁止在 `REPORT_SPEC` 中要求「过去一年叙事变化/第二步复盘五问」。

## 一、REPORT_SPEC（默认，强制）

```
围绕 {公司名}（{code}），按穿透叙事「客观列示版」生成机构级深度报告。正式可交付，缺一则不合格。

【立场红线—默认模式】
- 禁止出现：本报告理论业绩空间/理论L区间、悲观中性乐观极限等本方分档情景、高估/低估/合理/透支等价值判断、买入卖出仓位等决策建议。
- 只做：DCF反算现价与券商目标价隐含终局利润L；客观列示一致预期、内外资券商与纪要点评中的市场观点；归纳乐观阵营与保守阵营差异；最新边际变化与中性观察信号。
- **禁止历史复盘（HARD）**：不得写「过去一年/半年叙事复盘」专章、叙事阶段表、对宽基超额切段、复盘五问；历史复盘仅用户显式要求时另模块处理。
- 券商目标价估值方法一律为与现价相同的DCF反算（dcf_implied），禁止改用PE/PEG/SOTP重估目标价。
- 默认模式不写等价反推专节；追问增补情景时若拆解 L=TAM×份额×净利率须自洽可审计，不评价要素可否达成。
- 文末【必写】两处：在「核心结论」最后一段与正文最后（附录前）各写一句：「默认模式不含本方情景与买卖建议。如需情景分档或投资建议框架，可明确追问」；不得在正文展开半套情景或软建议。

【报告开头声明（必备，置于核心结论之前）】报告最前面先写「口径、方法与机构搜索范围声明」：①数据口径（分析基准日与最近已收盘交易日、货币与单位、价格/股本口径、E0 与 E1–E3 口径及一致预期日期、已披露中报进度并列说明）；②方法（统一 DCF 反算框架：基准年/稳态年/过渡期/r 三档/永续假设，L/E3 与 L/E0 定义，券商目标价一律同框架反算，关键词热度分母分子与 Z 分定义）；③机构搜索范围（列出主动检索过的外资与内资机构，并声明未检索到可复核目标价者）。

【核心结论】开篇≥800字，至少5条独立段：
① 现价隐含L（r=8/10/12%）+ L/E0 + L/E3（描述性标签可，结论性贵贱不可）
② 各券商目标价DCF隐含L分布、相对现价的离散；外资/内资差异只陈述
③ 乐观vs保守阵营在关键变量上的观点对照
④ 最新边际变化与市场当前关注点摘要（**不是**历史行情复盘）
⑤ 市场可能关注的检验信号（中性列表）
禁止「决策建议」专条；禁止「过去一年叙事变化摘要」专条。**核心结论最后一段必写**：「默认模式不含本方情景与买卖建议。如需情景分档或投资建议框架，可明确追问」。

【必备章节与表】
第一步：
 - DCF输入参数表、反算结果表（L/L/E3/L/E0/g/动态PE）、L/E3描述分级表、盈利周期事实表（**不再单列敏感性专节**——折现率敏感性由 L/E3 分级表承载）
 - 可并列一致预期滞后时的校正口径反算，不裁定哪套「正确」
券商观点专节（深度≥1100字，分两个小节）：
 **搜索范围（强制）**：主动搜索外资（高盛、摩根士丹利、瑞银UBS、花旗Citi、摩根大通JPMorgan、汇丰HSBC、瑞杰Raymond James、伯恩斯坦Bernstein、Barclays）与内资（中金、中信、国君、华泰、招商、天风、长江、华源、兴业、华创、国盛、中信建投、开源、中泰）对该公司的覆盖/目标价/盈利预测；报告开头声明搜索过的机构范围（未检索到也要写明）。
 **小节 A·有目标价的券商**（一律 DCF 反算）：
 - 逐家表：机构、内外资、日期、评级、目标价、市值=价×股本、DCF隐含L（至少r=10%，建议三档）、L/E3、L/E0、相对现价隐含L
 - 逐家DCF文字；乐观vs保守假设拆解表（摘录市场原假设，不写本报告采信）
 **小节 B·无目标价的券商**（大部分内资常见）：
 - 表格列示：机构、日期、评级（若有）、未来三年盈利预测（E1/E2/E3或原文口径）、主要观点/关键假设摘要
 - 文字汇总：按乐观/中性/保守阵营归纳路径假设与关键分歧（不做DCF反算，不判对错）
（已删除默认第二步复盘）禁止输出：涨跌对照表、叙事阶段表、复盘五问、对宽基超额切段——历史复盘仅用户显式要求时走 retrospective 模块。
第三步：观察信号清单与最新边际变化补充（尤其是未体现在券商研报中的最新信息）
关键词市场热度小节（默认必做）：详细复合叙事标签（10–14 个，非单词简称）+ 过去一年月度渗透率热力图（绝对值）+ 近1月相对历史 Z 分排序图（边际）；配标签表、排序表与上修/稳态/回落三簇文字；口径与方法见 `keyword-heat-module.md`。
第四步客观收束表（**必备、必须成表**）：一张两列表——左列「当前客观事实」、右列「市场分歧核心」，逐维度覆盖股价市值/近端盈利/指引/一致预期/现价隐含L/券商共识L（有目标价部分）/2–3个关键叙事变量；表后配解读。**无高估低估列、无操作建议列，不得折叠成纯段落**。
（已删除）不再输出等价反推专节：默认报告不写 L=TAM×份额×净利率 的等价反推专节（已应用户要求删除）；若用户追问情景再在增补篇拆解。
正文最后（附录前）：再写一句「默认模式不含本方情景与买卖建议。如需情景分档或投资建议框架，可明确追问」。
附录：数据口径时点概括；无来源清单；免责「不构成投资建议」

【字数】深度正文约≥1万字信息量；每表配套解读；段落短、小点分行。
【来源展示】正文与附录不出现source标记；须写清券商机构名与报告日。
【禁止】Mermaid；除「关键词市场热度」小节的两张热度图外不插图（该两图由 `keyword_heat.py` 生成并嵌入）。
```

## 二、交付

- 默认 **md** 深度报告。
- **强制附** Excel DCF 工作簿：`scripts/build_dcf_workbook.py build` → `{公司名}_穿透叙事_DCF模板.xlsx`（三表版式见 `dcf-workbook.md` / `assets/dcf_template.xlsx`）。与 md **同一套**市值/股本/E1–E3/目标价。
- DOCX 可选：`scripts/generate_report.py` + content JSON；与 md **同源**，同样遵守默认立场红线。
- 追问增补优先独立 md：`{公司名}_穿透叙事_情景与建议增补.md`。

## 三、自检（默认报告）

- [ ] 全文无「理论区间」「高估」「低估」「建议买入/卖出」「本报告认为合理」
- [ ] 全部目标价均有 DCF 隐含 L，无单独 PE 估值重算段
- [ ] 有乐观/保守阵营客观对照
- [ ] 有现价隐含 L 三档
- [ ] **默认报告无历史复盘专章**（无过去一年/半年叙事复盘、无阶段表/五问/宽基超额切段）
- [ ] 免责声明
- [ ] 未夹带本方四档情景表或仓位建议
- [ ] **有第四步客观收束表（两列：客观事实 / 市场分歧），已成表而非纯段落**
- [ ] **默认报告已删除等价反推专节**（全文无「等价反推专节」标题，无强制 2–3 组 TAM×份额×净利率 默认段落）
- [ ] 券商观点专节已分 **A 有目标价 / B 无目标价** 两小节；有目标价均做 DCF；无目标价有三年盈利预测表+阵营文字
- [ ] 已搜索并声明外资（高盛/大摩/瑞银/花旗/摩根大通/汇丰/瑞杰/伯恩斯坦/Barclays）与内资（中金/中信/国君/华泰/招商/天风/长江/华源/兴业/华创/国盛/中信建投/开源/中泰）检索范围
- [ ] **核心结论末段与正文末（附录前）**均出现固定提示句：「默认模式不含本方情景与买卖建议。如需情景分档或投资建议框架，可明确追问」
- [ ] **报告最前面有「口径、方法与机构搜索范围声明」**（口径/方法/机构检索范围三项齐全）
- [ ] **含「关键词市场热度」小节**：10–14 个详细复合叙事标签 + 绝对值热力图 + 近1月 Z 分排序图 + 表后解读
- [ ] **未输出敏感性分析专节**（折现率敏感性仅由 L/E3 分级表承载）
- [ ] 已交付 `{公司名}_穿透叙事_DCF模板.xlsx`，三表齐全，隐含 L 与 md/脚本一致

## 四、模式与档位

对话/报告 DCF 与阵营数字同源。速览可压缩券商逐家文字；标准保留总表+阵营；深度逐家 DCF 展开。默认三档都**不得**恢复理论区间与决策段。

## 五、追问增补规格（仅用户明确要求时使用）

详情与表格规范见 `optional-scenario-advice.md`。可据此生成独立增补篇：

```
围绕 {公司名}（{code}），在已完成的穿透叙事「客观列示」材料与（若有）默认报告基础上，生成「情景分析与（按需）投资建议」追问增补篇。文首注明：本节/本文应客户追问生成，不替代客观列示正文。

【必须承接】
- 沿用同一套市值、股本、E1/E2/E3、稳态年与已公布的现价隐含L、券商目标价隐含L，不得另起一套DCF口径。
- 先用一小段复述客观事实锚点（隐含L与券商分布），再展开增补。

【情景分析—必做】
- 给出本方分档情景表（默认保守/基准/乐观/极乐观；周期股可改名并说明）。
- 每档 L 必须可审计：L=TAM×份额×净利率（或披露替代路径），写清假设依据类型。
- 对各档 L 用与主报告相同的DCF正算市值（至少 r=10%），并给对应股价。
- 将现价隐含L（三档r）与主要券商隐含L映射到最近情景档，做位置关系表。
- 位置结论必须写成「相对本方情景…」，可使用偏低估/中性/偏高估/接近上沿等用语，并披露情景不确定性。

【投资建议—仅当用户明确要求建议/买不买/仓位时】
- 输出条件化建议框架 + 观察信号→框架动作表，禁止保证收益与绝对喊单。
- 写明失效条件与免责「不构成正式投资建议」。
- 若用户只要情景、不要建议，则整节删除建议，只保留情景与位置。

【禁止】
- 用PE/PEG/SOTP另估目标价替代DCF正算。
- 先拍L再倒填三要素而不披露。
- 把增补措辞写成默认客观结论、抹去「相对本方情景」限定。

【形式】表格+短段落；可无万字；禁止图片与Mermaid；无source数字标记。
```

### 增补自检

- [ ] 有用户追问依据
- [ ] 情景 L 可审计
- [ ] 与现价/券商隐含 L 对照完成
- [ ] 建议（若有）为条件化框架且有免责
