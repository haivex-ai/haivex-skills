# 叙事行情复盘模块（专项）

触发话术（**必须显式命中**才走本模块；仅「分析某公司/叙事/隐含预期/出报告」**不触发**，默认深度报告**禁止**内嵌本模块压缩版）：

- 「复盘某某公司某段时间行情」「复盘 XX 从 YYYY 到 YYYY」
- 「叙事复盘 / 超额收益复盘 / 行情复盘 / 阶段叙事切分」
- 「逐日复盘 / 这一周复盘」（跨度 ≤7 个自然日 → 短窗模板）

**与默认分析的边界（HARD）**：
- 未命中上列话术 → **不要读本文件**，不要取复盘行情、不要写复盘报告。
- 命中复盘话术 → 本模块**优先于**默认「当下隐含 L 深度报告」；除非用户同时要求分析+复盘，否则不展开全量券商目标价深度报告。
- 同时要求时：默认客观列示与复盘**分文件或分专章**，复盘专章须标明应复盘请求生成。

本模块目标：用**叙事时段**（非自然季/年）解释涨跌；用相对宽基的超额识别兑现 vs 变化；在变化起点用**当时**一致预期/盈利预测做 DCF 反算还原隐含 L 跃迁；**禁止后视镜**（解读只用截止该时点可得信息）；事后再用兑现与修正评价新叙事。

经典展开节奏对齐 `case-studies.md` 与《穿透叙事》第二～五章：先切段 → 再还原 L → 再基本面叙事 → 再评价兑现 → 再抽产业规律。

## 一、两套模板（按时间跨度）

| 模板 | 触发 | 切分粒度 | 深度重心 |
|------|------|----------|----------|
| **A·长跨度叙事复盘** | 复盘窗口 **>7 个自然日**（默认；跨月/跨年/「上市以来」） | 以叙事变化起止切段；**只抓重大叙事变化**，忽略噪声脉冲 | 重大向上/向下叙事 + 长兑现段；产业链规律总结 |
| **B·短窗逐日复盘** | 复盘窗口 **≤7 个自然日**（或用户明确「逐日」） | **逐日**（交易日）对照指数 | 边际变化、传闻/交易性冲击；不强行构造终局 L 大故事 |

跨度边界：起止日用户给定；未给止日默认「起日 → 最新已收盘交易日」。跨度按自然日计。

## 二、宽基对标与「叙事变化」判定（HARD）

### 2.1 对标指数（大致重合即可，不要求严丝合缝）

| 标的类型 | 默认宽基 |
|----------|----------|
| 沪深主板、多数非创/科 A 股 | **沪深300** |
| 创业板、科创板 | **创业板指** |
| 港股 | 恒生指数或恒生科技（按公司属性择一，文中声明） |
| 美股 | 标普500 或纳斯达克100（成长/科技偏 NDX，文中声明） |

可选辅线（不替代主对标）：同业龙头、行业指数——用于区分「板块 beta 叙事」vs「个股 alpha 叙事」（如隆基 vs 保利协鑫的 X 交叉）。

### 2.2 阶段标签（用累计收益曲线相对宽基，多起点滑动观察）

不断变换累计涨跌幅**计算起点**，观察个股与宽基是否大致重合：

| 标签 | 判定（启发式，允许肉眼级近似） | 叙事含义 |
|------|--------------------------------|----------|
| **兑现叙事** | 一段时间内走势与宽基**大致重合** | 终局 L 共识大体稳定；收益≈必要收益（折现率量级），业绩用来消化估值 |
| **向上叙事变化** | **持续**相对跑赢（累计超额抬升，非单日异动） | 市场上修业绩天花板 L |
| **向下叙事变化** | **持续**相对跑输 | 市场下修 L |
| **交易性/传闻脉冲** | 突然大涨或大跌后**很快回吐或修复**，相对宽基尖峰后回归 | **不要强行归因基本面**；可写宏观冲击、流动性、不实传闻、博弈；简述即可 |
| **纯宏观/beta** | 个股与宽基同向大幅波动且相对曲线仍贴合；或个股波动主要拟合全市场成交额/风险偏好 | 折现率/流动性（「竖着拔估值」），非 L 上修；可对比指数，勿编造公司基本面故事 |

**禁止**：用自然季度、半年度、年度当主切分轴（可作附注）。  
**禁止**：把「业绩超预期但相对指数无超额」写成叙事上修。  
**禁止**：把单日涨停/跌停且快速回归写成重大叙事变化。

### 2.3 重大 vs 次要（长跨度）

长跨度只保留：

1. 相对宽基累计超额曲线出现**可持续拐点**（通常数周以上，政策驱动可短至数周内「结束战斗」）；
2. 或市值/动态 PE 隐含 L 发生**台阶式**变化；
3. 同业相对走势出现结构性分叉（王位易主、路线之争）。

短暂脉冲、假突破、快速回撤 → 归入交易性因素附录或段内一句带过。

---



### 2.4 外向型/海外产业链关联标的：大幅波动的双市场检索（HARD）

当标的**收入、客户、定价或叙事锚**明显依赖海外（北美 CSP、GPU 生态、出口链、港美交叉上市等）时：

1. **股价出现重大上修/下修段或急涨急跌**，资料收集**不得**只查国内宏观（社融、宽基、国内政策）。
2. **必须并行匹配**：
   - 海外**上游**：关键芯片/设备/平台（如 GPU、DSP、光芯片）、技术路线冲击（开源模型、效率革命、CPO 等）；
   - 海外**下游**：CSP/云厂商 capex 指引与财报、同业美股/韩股价格与叙事；
   - **跨市场共振**：中美（或中韩）算力/硬件链是否同向大幅波动；
   - 贸易/出口管制/关税等**地缘变量**（常与叙事冲击叠加，但未必是第一段主因）。
3. 归因写作：**先时间对齐海外事件与股价拐点**，再写国内映射；禁止把「关税/国内 beta」写成唯一主因而遗漏全球叙事（反例纠正：中际旭创 2025-01～04 回撤 = DeepSeek-R1「杀伤算力」中美共振 → 4 月贸易战极悲观）。
4. 工具：`search_web` / `search_paipai` / `search_global_data`（海外行情）+ 国内公告纪要；段内信息集仍遵守 `end_time`≤时点。


## 三、分析工作流（五步，顺序强制）

### 步骤1：时间轴切段——寻找兑现期与变化期

**取数（强制）**

- 委托 `data_analyst`：复盘区间内个股**前复权**日收盘、对标宽基日收盘；输出日期、个股、指数、可选归一化净值（起点=1）。
- A/H/美股注意复权与汇率：市值口径与 DCF 一致；港美可 `search_global_data`（先读 skill）或 DA 美股/港股域。
- 交易日边界用 `trading_calendar`（对应市场）。
- 落盘：`tmp/{session_id}/retro_prices.json`（或 csv）+ 简表 md。

**切段方法**

1. 计算区间内多起点的个股 vs 指数累计收益差（或相对强度）。
2. 标出：持续跑赢段 / 持续跑输段 / 重合段 / 尖峰脉冲。
3. 产出**叙事时间表**（主表）：

| 叙事段 ID | 起止交易日 | 标签（兑现/上修/下修/脉冲/宏观beta） | 个股区间涨跌 | 宽基区间涨跌 | 相对超额 | 一句话现象 |

长跨度：合并碎段，只留重大段。短窗：按交易日填表，标签可细到「脉冲」。

### 步骤2：变化起点的 DCF 反算——还原当时预期与隐含 L

对每个**叙事变化段的起点**（及可选终点高点/低点）：

1. 取该交易日（或当时）市值/股价、总股本；
2. 取**当时**一致预期或券商 E1/E2/E3（或当年动态 PE + 当时盈利预测）——**禁止用今日一致预期回填历史**；
3. 用与主框架相同的 `scripts/dcf_implied.py`（r=8%/10%/12%，默认稳态年规则与主 skill 一致）反算隐含 L、L/E0、L/E3、动态 PE；
4. 若历史一致预期不可得：用「当时动态 PE + 查表/反算」说明局限，或用最接近时点的卖方预测并标注日期缺口。

产出表：

| 时点 | 市值 | 当时 E 或 PE | r=10% 隐含 L | L/E_then | 段末同口径隐含 L | ΔL 含义（上修/下修倍数） |

变化段内：对比起点 vs 终点隐含 L，量化「天花板上修/下修了多少」。

兑现段：验证隐含 L 大致平移、PE 随业绩消化——呼应案例中「涨5倍业绩无超额」。

### 步骤3：基本面解读——旧叙事 / 何因改变 / 新叙事（无后视镜）

对每个重大变化段，按案例五问展开（长文；短窗可压缩）：

1. **旧叙事是什么**（终局 L 对应何种 TAM×份额×利润率或周期中枢，用变化前市场语言）；
2. **为何旧叙事被修正**（截止变化发生时已公开的产业/政策/公司事实）；
3. **新叙事关键变量**（尽量落到空间/份额/利润率或第二曲线）；
4. **诱发因素**（政策文件、技术拐点、订单/价格、战略并购、宏观社融等——与股价拐点对齐）；
5. **新叙事形成标志**（超额收益结束、重与宽基重合的时点）。

资料口径：

- 公告/研报/纪要/新闻的 **`end_time` ≤ 该段讨论时点**（或明确「时点 T 的信息集」）；
- 可用 `doc_searcher` / `search_paipai` 按历史窗口检索；政策原文可用 `search_web`；
- **切实关闭后视镜**：不得用「后来证明…」作为段内归因主句（评价留给步骤4）。

区分：

- 同业同涨 → 偏**空间**叙事；
- 此消彼长 → 偏**份额/路线**；
- 独立行情 → 偏利润率/个股故事/交易结构；
- 与宽基同步的大波段 → 先写宏观/流动性，再写是否叠加公司 L 变化。

### 步骤4：评价新叙事——是否兑现、被什么修正

用**变化段结束之后**的股价路径 + 业绩兑现：

| 评价 | 含义 |
|------|------|
| 兑现良好 | 此后长期与宽基重合，业绩向新 L 靠近，无新的持续超额 |
| 新叙事过满 | 随后持续跑输或隐含 L 下修；或逻辑被政策/技术证伪 |
| 叙事接力 | 尚未充分兑现又出现下一次上修/下修（如隆基三次上修） |
| 脉冲无效 | 快速回归，步骤1已标为交易性 |

可引用后来的财报、份额、价格，但必须标注「事后检验」，与步骤3信息集分离。

默认复盘模式**可以**评价「新叙事是否兑现/被修正」（这是复盘目的），仍**不**给买卖建议、不写「应在何时买入」操作指南；若用户另要投资建议，走主 skill 追问增补。

### 步骤5：总结产业链/机制规律

至少 5 条可迁移规律，对齐经典案例库口径，例如：

- 超额收益窗口短，与产业趋势长度无关；
- 股价打提前量；分歧是上涨动力；
- 政策变化往往更快形成一致预期；
- 兑现期业绩再好也无 alpha；
- 向下定价慢于向上；镜像产业链进度条不同步；
- 交易性/流动性冲击涨跌同源，难上台阶；
- 对标逻辑与故事循环的陷阱（乐视类）等。

结合**本标的**复盘证据写，避免空洞清单。

## 四、报告结构模板

### 模板 A·长跨度（文件名示例）

`{公司}_叙事行情复盘_{起点}_{终点}.md`

**完整写作规格 + 取数/作图清单（由协鑫科技 2014–2022 终稿反向固化）**：必读并优先采用
`references/retrospective-long-span-prompt.md`。

结构摘要（与终稿一致；细节以该 prompt 为准）：

1. **复盘结论（客观）**：全区间个股/宽基累计涨跌与超额；最大回撤；**alpha 是否集中于极短主升段**（给出起止与超额）；旧/新叙事主线与案例镜像一句。
2. **数据与口径**：复权、宽基、币种、DCF 与历史预期局限表。
3. **关键年度与全区间表现表** → **图2 业绩×股价合图（默认不含宽基）** → **关键价格拐点表**。
4. **叙事时间表** → **图1 全区间个股 vs 宽基归一化** → 相对强度主结论（≥3 条）。
5. **分叙事段展开**：每段 **先嵌图Si（段内 vs 宽基）** → 步骤2 隐含 L 表 → 步骤3 五问 → 步骤4 事后检验。
6. **交易性/宏观脉冲附录**（窗口表、股本市值、同业辅线等）。
7. **步骤5 规律总结**（≥5 条，带本标的数字）。
8. **免责**。

**作图默认必出**（visualization/Python，落 `tmp/.../img/`）：图1 全区间相对；图2 仅业绩+股价；图S1…Sn 各段相对宽基。禁止 Mermaid。

深度：重大段写透；次要段表格化。参考案例信息密度（隆基三起、煤炭多段、茅台六段、乐视故事+财报+流动性）。

### 模板 B·短窗逐日

`{公司}_叙事短窗复盘_{起点}_{终点}.md`

**完整可粘贴结构 + 取数/DCF 清单（由《中际旭创_叙事短窗复盘_20260911_20260918》终稿反向固化）**：必读并优先采用
`references/retrospective-short-window-prompt.md`。

**HARD（短窗也必做）：开篇前置「叙事绝对水位」**——用与主框架相同的 `dcf_implied.py`，对**窗口末/最新已收盘**与**窗口内关键价位时点**（高点/低点/事件日）反算隐含 L（至少 r=10%，建议三档）、L/E3、L/E0（有 E0 时）、动态 PE(E1)。一致预期用**当时/最新可得** E1–E3（禁用无关期史预测回填日线）。有热议目标价时同一口径 `brokers` 做舆论带宽。

**为何强制**：短周期涨跌往往**不来自**最新一条边际新闻，而是**叙事绝对水位已偏高/偏低**时，对折现率、拥挤筹码、事件概率的再定价。未先量水位，禁止把高位震荡写成「基本面一日变天」。

结构摘要（细节以 short-window-prompt 为准）：

0. **叙事绝对水位（DCF）**：纪律导语；E0–E3 与 E3/E0；关键时点隐含 L 表 + 读数三条；目标价 L 带宽；**水位→涨跌解释四问表**。
1. 窗口结论表 + 一句话（点明水位内 / 边际 / L 台阶）。
2. **逐日表** + 区间累计（含 ΔL）+ 可选脉冲形状表。
3. 主脉冲五问压缩（结合水位）+ 事后检验。
4. 机制规律 ≥5 条（带本窗数字）+ 中性观察信号。
5. 口径附录 + 免责；**不强制** Excel 工作簿；默认 `write_file` 成文。

## 七、案例框架锚点（写作时对齐）

- **光伏/隆基式**：多起点切段；三次 L 上修 + 长兑现；政策 vs 市场化时长；PE 与 L 倍数印证；流动性后半段纯 beta。
- **煤炭式**：高景气长兑现无 alpha；脉冲需求与供给约束；学习效应导致行情分段；上下游镜像业绩非镜像行情。
- **白酒/茅台式**：五问切段；商业模式叙事；表征空间的可观察变量（如批价/出厂价）与相对 PE。
- **乐视式**：故事叙事 + 监管证伪 + 报表结构 + 流动性/杠杆 beta（相对创业板倍增拟合）；区分 alpha 段与纯 beta 段。
