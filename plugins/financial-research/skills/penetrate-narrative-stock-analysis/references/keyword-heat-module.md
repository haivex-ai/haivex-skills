# 关键词市场热度模块（叙事热度：过去一年绝对值 + 近1月边际）

> 用途：在**默认深度报告**中增设一节「关键词市场热度」，把研报/纪要/点评/社媒等文本中围绕该公司的**叙事议程**，压缩为可比较的热度刻度：
> **① 过去一年绝对值**（月度渗透率热力图）与 **② 近1个月边际变化**（相对历史 Z 分排序）。
> 逻辑基础：叙事变化是超额收益来源；文本议程权重的抬升/回落，是叙事变化的**可观测代理**（代理，非股价驱动充分统计量）。

---

## 一、何时使用

- **默认深度报告**：作为独立小节输出（建议编号在「最新边际变化/纪要要点」之后、观察信号清单之前，如 §5.1.5）。
- 对话快答/研讨：可不落图，只口头给「近月抬升/回落的叙事」。
- **复盘专项**：按 `retrospective-module.md` 处理，本节不是复盘替代物（复盘用行情+历史盈利预测反算，本节用文本词频）。

## 二、关键词设计原则（关键）

1. **用详细复合叙事标签，不用单词简称**。标签应为 3–8 字的**名词短语 + 动作/方向**，例如「1.6T放量/接棒主力」「供应链锁料/物料紧缺」，而不是「1.6T」「供应链」。
2. **每个标签配 3–10 个同义词/近义写法**（中英、缩写、常见错写、场景词），组成**同义词簇**命中，降低漏召与跨义混淆。
3. **数量 10–14 个**：太少无法区分议程结构，太多会稀释单条渗透率。
4. **贴合公司特点**：由该公司的主营产品、下一代技术、成本/供给约束、资本运作、客户结构、产能布局等决定。禁止套用无关行业的模板。
5. 标签之间尽量**互斥、可解释**；若某类内部差异大（如「供应链」可拆 EML/DSP/预付款），可在追问时拆细。

导出默认模板（示例为光模块/AI 算力链龙头，需按标的改写）：
```bash
python skills/user/penetrate-narrative-stock-analysis/scripts/keyword_heat.py --dump-keyword-template
```

## 三、取数（第零步的一部分）

用 `doc_searcher`（保证完整性）拉取过去约 12 个月、**公司相关**的文本，多源合并：

| 来源 | 说明 |
| --- | --- |
| 卖方研报（`research_reports`） | 个股公司研究为主（`stock.code` 精确过滤） |
| 路演/电话会纪要（`roadshow_transcripts`） | 业绩解读、行业动态解读 |
| 券商点评（`sell_side_comments`） | 时效高，注意按证券标签去噪 |
| 社媒/公众号（`social_media_articles`） | 线索性，需去噪 |
| 基金经理观点（`fund_manager_viewpoints`） | 持仓与叙事讨论 |
| 蓝宝书/机构热议 | 仅在正文直接绑定该标的时并入，避免虚增分母 |

每源 `save_as` 独立 `.json`；时间窗跨度 >3 天时要求子 Agent **按月分片**检索再合并，以保证穷举。

## 四、计算口径（由脚本固化）

- **分母** = 当月「公司相关」文档数（正文或标签命中公司名/代码，且非空正文）。
- **分子** = 当月正文/标题命中该叙事同义词簇的文档数；**同月同文档同叙事只计 1 次**。
- **渗透率(%)** = 分子 ÷ 分母 × 100。
- **近月** = 最近一个**完整自然月**（分析日在月中时，取**上月**，显式传 `--recent-month`）。
- **Z 分** = (近月渗透率 − 历史月均值) ÷ 历史月标准差；**经验分位** = 历史月中 ≤ 近月的比例。
- 图 A 绝对值用**热力图**（Reds，0–100）；图 B 边际用**横向条形**（红=高于历史、绿=低于历史）。

## 五、脚本用法

```bash
python skills/user/penetrate-narrative-stock-analysis/scripts/keyword_heat.py \
  --inputs tmp/{sid}/tool_outputs/research_all.json,tmp/{sid}/tool_outputs/roadshow_all.json,tmp/{sid}/tool_outputs/comments_all.json,tmp/{sid}/tool_outputs/social_all.json \
  --company {公司名} --code {代码}.SZ \
  --recent-month {上月} \
  --out-json tmp/{sid}/tool_outputs/keyword_heat_monthly.json \
  --out-summary tmp/{sid}/tool_outputs/keyword_heat_summary.md \
  --img-dir tmp/{sid}/img
```

- 自定义关键词：先 `--dump-keyword-template`，改写后存 `keywords.json`，用 `--keywords-json` 传入。
- 默认时间窗 = 数据最小月～最大月；需要固定窗时用 `--start-month/--end-month`。
- 输出：`keyword_heat_monthly.json`（矩阵与 Z 分）、`keyword_heat_summary.md`、两张 PNG。

## 六、报告小节写法

1. 先给**口径与方法**：关键词个数、样本窗口与去噪后文档量、分母/分子/渗透率定义、近月与历史对照窗。
2. 列**详细叙事标签表**（编号 + 标签 + 同义词簇摘要）。
3. 嵌 **图A（绝对值热力图）**，配「绝对值水位」解读表（各标签常年高/中/低与波动特征）。
4. 嵌 **图B（近月 Z 分排序）**，配**排序表**（近月渗透率/历史均值/Z/分位/Δ百分点）。
5. **文字归纳**分三簇：上修簇（Z 显著正）、高位稳态簇（Z 近中性）、相对回落簇（Z 负），并与纪要/公告议程交叉对照。
6. **使用边界**：词频渗透率=文本议程权重，非出货量/份额/股价驱动充分统计量；边际解读优先看 Z 与排序，而非单月百分点。
7. 禁止：把热度直接写成「高估/低估/买卖」结论（默认模式立场红线不变）。
