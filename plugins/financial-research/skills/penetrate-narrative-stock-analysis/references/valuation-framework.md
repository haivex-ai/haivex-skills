# 估值框架：DCF反算隐含天花板

本文件解释穿透叙事框架的核心估值方法——如何用DCF反算股价隐含的终局利润（天花板高度）。SKILL.md第一步的详细依据。

## 一、为什么用DCF反算而非查表

原书的表2-3（天花板高度m × 折现率r → 动态PE）基于"匀速等比增长"假设，要求公司从当前时点起匀速增长至天花板。但现实中：

- 多数公司增速并非匀速，早期快、后期慢，或受周期影响波动
- "匀速增长"假设对成熟期公司尚可，对转型期、周期股、早期成长股偏差大
- 查表法隐含的m是"天花板较当前业绩的倍数"，但当前业绩本身可能受周期干扰（如周期股业绩高点/低点）

**改进方法**：不再假设全期匀速增长并查表反算m，而是用更贴近现实的分阶段DCF模型，直接反算股价隐含的**终局利润绝对值L**：

- 前3年用分析师一致预期（反映近期可见的成长路径，无需自己拍增速）
- 第4年至稳态年（默认2035）从第3年起匀速增长至天花板（过渡期，增长年数N=稳态年-基准年-3）
- 稳态年+1起永续稳定（不给予永续增长率，避免预期打太满）

这样得到的L是绝对值。默认模式仅与市场表述、券商目标价隐含L对照；仅当用户追问情景/理论空间时，才与本方情景表L对照。不依赖"当前业绩"这个可能失真的基准。

## 二、DCF反算模型

### 2.1 模型设定（v2.4.0：稳态期默认2035年）

| 阶段 | 时段 | 业绩假设 |
|------|------|----------|
| 近期 | t=1,2,3（即基准年+1至+3） | 分析师一致预期 E1, E2, E3 |
| 过渡期 | t=4..3+N（即基准年+4至稳态年） | 从 E3 匀速（等比）增长至终局 L |
| 永续期 | t=4+N,...∞（即稳态年+1起） | L 永续稳定（g=0） |

其中 N = 稳态年 - (基准年 + 3)。默认基准年=2025，稳态年=2035，故 N=7（即2029-2035共7年匀速增长，2036起永续稳定）。

**关键假设**：
1. 净利润 ≈ 权益现金流（忽略营运资本变动）。若公司权益现金流远低于净利润（重资产/应收高/资本开支大），算出的L偏高，应定性下调。
2. 过渡期为等比增长（复合增速恒定）。第4年至稳态年复合增速 g = (L/E3)^(1/N) - 1。
3. 不给予永续增长率（g=0）。原书明确"不建议给任何公司永续增长假设"，100年前标普500与现在重合度不到10%。
4. 折现率三档：8%、10%、12%，不用CAPM算"精确的错误"。
5. 稳态年默认2035（v2.4.0变更），用户可通过 `--steady-year` 参数覆盖。

### 2.2 DCF公式

```
市值 = Σ(t=1..3)  E_t / (1+r)^t                           # 近期
     + Σ(t=4..3+N)  E_3·(1+g)^(t-3) / (1+r)^t             # 过渡期, g=(L/E3)^(1/N)-1
     + (L / r) / (1+r)^(3+N)                                # 永续期现值（折回当期）
```

给定市值、E1-E3、r、N，用二分法反解 L。

### 2.3 折现率三档的含义

| 折现率 | 适用场景 | 含义 |
|--------|----------|------|
| 8% | 低协方差红利资产（长江电力、神华等穿越周期的稳定类） | 风险溢价低，已证明与宏观经济弱相关 |
| 10% | 默认中性档，适用于大部分公司 | A股权益折现率的长期经验值 |
| 12% | 高风险公司、流动性折价、小盘股 | 风险溢价高，不确定性大 |

**为什么不直接取无风险利率+CAPM算的折现率？** 因为CAPM算出的值往往是"精确的错误"——"全市场平均的风险溢价"本应是客观动态变量，但习惯上视为固定常数，导致权益折现率随无风险利率等额变化的误区。实际中，无风险利率下行时风险溢价往往上升（因增长机会减少），两者对冲，权益折现率长期稳定。

三档给出区间而非单点，更诚实反映不确定性。分析时以10%为主，8%和12%为敏感度边界。

### 2.4 反算结果的解读

反算出 L 后，计算 L/E3 倍数（隐含天花板相对第3年业绩的倍数），按下表初判：

| L/E3 倍数 | 市场隐含预期（描述标签） | 默认模式用法 | 追问增补模式（可选） |
|-----------|--------------------------|--------------|----------------------|
| <0.3 | 业绩深度下滑 | 只描述倍数含义 | 可对照本方情景判断是否显著低于情景下沿 |
| 0.3-0.5 | 业绩显著下滑 | 周期股低点常见表述 | 同上，结合标准化利润 |
| 0.5-1.0 | 业绩温和下滑或持平 | 描述为偏低增长预期 | 可讨论相对情景的赔率 |
| 1.0-2.0 | 温和增长 | 正常描述区间 | 对照基准情景 |
| 2.0-5.0 | 较高增长 | 描述强度，不写可达结论 | 验证三要素是否支撑 |
| 5.0-10.0 | 高增长 | 描述「叙事较饱满」 | 可写相对情景上沿/透支 |
| >10.0 | 极高增长 | 描述「隐含极高终局」 | 可写打满/需更宏大叙事 |

同时计算第4年至稳态年隐含复合增速 g = (L/E3)^(1/N)-1；默认模式与历史/行业增速**对照陈述**即可。高估低估类用语仅限追问增补。

## 三、使用方法

### 3.0 报告附件：Excel DCF 工作簿（强制）

与 CLI 反算并行，报告必须产出与本模型一致的三表 Excel（版式对齐上传样例）：

- `Assumptions`：黄格输入 + 正算公式（PV/市值/股价）+ 现价隐含 L 三档固化表
- `券商目标价隐含L`：目标价→市值公式→三档隐含 L；相对现价 L 引用 `Assumptions!$B$33`
- `敏感性_L到市值`：不同 L 对应市值/动态 PE

```bash
python scripts/build_dcf_workbook.py build --input dcf_params.json --out {公司}_穿透叙事_DCF模板.xlsx
```

字段、params 示例与自检见 `references/dcf-workbook.md`。数字必须与下方 CLI 反算一致。

### 3.1 反算隐含终局利润（核心）

```bash
python scripts/dcf_implied.py implied --cap <市值> --e1 <E1> --e2 <E2> --e3 <E3>
```

默认稳态年2035（N=7）。同时输出三档折现率（8/10/12%）下的隐含终局L、L/E3倍数、L/E0倍数、隐含增速g、动态PE，并自动执行反向验证（误差<5%）。

**示例**：某公司当前市值1000亿，未来3年一致预期净利润10/11/12亿：
```bash
python scripts/dcf_implied.py implied --cap 1000 --e1 10 --e2 11 --e3 12
```

**指定其他稳态年**（如2040）：
```bash
python scripts/dcf_implied.py implied --cap 1000 --e1 10 --e2 11 --e3 12 --steady-year 2040
```



### 3.2 敏感性分析

```bash
python scripts/dcf_implied.py sensitivity --e1 <E1> --e2 <E2> --e3 <E3> --r <折现率>
```

输出不同L/E3倍数（0.3x~20x）对应的合理市值与动态PE，便于快速定位。

### 3.3 券商目标价批量反算（v2.4.0新增）

```bash
python scripts/dcf_implied.py brokers --e1 <E1> --e2 <E2> --e3 <E3> --shares <总股本> \
    --prices <目标价列表> --names <场景名称列表>
```

批量反算各券商目标价隐含的终局利润L（三档折现率），用于与现价隐含L横向比较；默认模式不评价券商「是否合理」。

**示例**：
```bash
python scripts/dcf_implied.py brokers --e1 95 --e2 116 --e3 142 --shares 66.37 \
    --prices 48.67,72.8,83,88 --names "当前股价,高盛,摩根士丹利,瑞银"
```

## 四、边界条件与注意事项

### 4.1 周期股

周期股业绩低点时PE无意义（E1-E3可能极低，反算L/E3极高），应结合周期高位业绩理解。可选处理：
- 用周期中位的标准化业绩替代E1-E3并**并列**披露
- 或直接用业绩高点的PE反推市场隐含的"远期业绩打折比例"（原书表3-2思路）

### 4.2 当前无业绩的公司

若E1-E3为负或接近0，DCF反算不适用（E3为0时g无定义）。此时回退到原书表2-8的"市值速算倍数"法：

| 到达年限n | r=8% | r=10% | r=12% |
|-----------|------|-------|-------|
| 3年 | 11.6 | 9.1 | 7.5 |
| 5年 | 10.8 | 8.3 | 6.7 |
| 10年 | 9.1 | 6.8 | 5.3 |
| 15年 | 7.7 | 5.6 | 4.2 |

用法：隐含终局利润 = 当前市值 / 倍数。但这类公司不确定性大，折现率至少取10%。

### 4.3 权益现金流≠净利润

DCF模型假设净利润≈权益现金流。若公司：
- 资本开支持续大于折旧（重资产扩张期）
- 应收账款大幅增长（回款差）
- 营运资本占用持续上升

则权益现金流<净利润，反算出的L偏高（市场用更少的现金流支撑了同样的市值），应定性下调L的合理性，或直接用权益现金流替代净利润重新计算。

### 4.4 一致预期的可靠性

E1-E3取Wind/同花顺一致预期，但需注意：
- 一致预期往往系统性偏高（A股大部分公司业绩低于预期且有惯性）
- 可用"一致预期×历史兑现率"作为调整后输入
- 默认模式：主口径用一致预期原值；若需展示敏感性，可并列「一致预期×历史兑现率」或打8折的**备口径反算**，不上升为贵贱结论
- 追问增补：可将不同E口径嵌入情景表假设中
