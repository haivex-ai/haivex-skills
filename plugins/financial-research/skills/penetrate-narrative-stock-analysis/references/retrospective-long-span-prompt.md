# 长跨度叙事行情复盘 · 写作规格

> **来源**：由终稿样板《协鑫科技_叙事行情复盘_2014_2022》反向固化。  
> **何时使用**：复盘窗口 **>7 个自然日**（跨月/跨年/上市以来）；与 `retrospective-module.md` 模板 A、五步工作流配套。  
> **使用**：完成取数/切段/DCF/证据包后，按本节结构替换占位符，并完成分析写作和 `write_file` 落盘。
> **禁止**：把本模板用于「当下隐含 L 深度报告」或短窗逐日（≤7 日用 `retrospective-short-window-prompt.md`）。

---

## 一、占位符（成文前填实）

| 占位符 | 含义 |
|--------|------|
| `{公司}` | 公司简称 |
| `{代码}` | 标准化代码（如 03800.HK / 601012.SH） |
| `{曾用名}` | 可选；无则删句 |
| `{起点}` `{终点}` | YYYY-MM-DD |
| `{宽基}` | 恒生指数 / 沪深300 / 创业板指 / NDX 等（文中声明） |
| `{辅线同业}` | 可选 1–2 家（份额/路线对照）；无则写「无辅线」 |
| `{案例锚点}` | 对齐 case-studies：隆基式/煤炭式/茅台式/乐视式/镜像对手 等 |
| `{证据包路径}` | learnings 或 table 下证据 md/csv 列表 |
| `{图目录}` | 已生成 png 的 img 目录；未生成则在成文前先画图再嵌 |

---

## 二、成文前强制产物（不可跳过）

1. **日线对齐**：个股前复权 + 宽基收盘，落盘 csv；算年度涨跌、全区间累计、最大回撤、多起点相对强度。  
2. **叙事切段**：重大段 S1…Sn（只抓可持续超额拐点，勿自然季年主轴）；表含起止、标签、个股%/宽基%/超额pp/一句话现象。  
3. **拐点表**：段界与局部高低点日期+前复权价。  
4. **业绩序列**：复盘窗内年报（或关键中报）归母净利；币种与市值口径分开标注。  
5. **时点 DCF**：各重大变化起点/终点（或最近可得时点）市值 + **当时** E1/E2/E3；无历史一致预期则用利润路径近似并**强制标注「非当时一致预期，仅为利润路径近似」**；`dcf_implied.py`，突出 r=10% L、L/E3、ΔL。  
6. **图（visualization / Python，落 `img/`）** —— **默认必出**（终稿样板标准）：  
   - **图1 全区间相对走势**：个股与宽基均段首=100 归一；可红/绿阴影标相对强弱。  
   - **图2 业绩×股价合图**：**仅**个股归一化股价（线）+ 年报归母净利（柱，红正绿负）；**默认不含宽基**（用户未要求对标线时不要画进图2）。  
   - **图S1…Sn**：每一重大叙事段各一张「个股 vs 宽基」归一化对照图；段首=100；图下图题。  
7. **证据包 md**：上述表与 DCF 数字、政策/产业时间线要点、可选同业窗口超额；供成文阶段读取。

## 三、写作规格（替换占位符后执行）

```text
你是《穿透叙事》框架下的「叙事行情复盘」写作者。严格按 retrospective-module 模板 A（长跨度）和本写作规格成文。

【标的与窗口】
- 公司：{公司}（{代码}{，曾用名：{曾用名}}）
- 复盘窗口：{起点} → {终点}
- 主对标宽基：{宽基}（文中声明；港股常用恒生，A 股主板沪深300，创/科创业板指）
- 辅线同业（可选）：{辅线同业}
- 案例锚点：{案例锚点}（写作节奏对齐 case-studies，勿整段粘贴案例库）

【硬性立场】
1) 用叙事时段（非自然季/年）解释涨跌；相对宽基识别兑现 vs 上修/下修 vs 脉冲/宏观 beta。
2) 禁止后视镜：段内归因只用截止该时点公开信息；「事后检验」单独成节并标注。
2b) **外向型/海外产业链关联标的**：重大波动段必须匹配海外上下游与跨市场叙事（CSP capex、美股同业、技术效率冲击、贸易政策），禁止仅用国内宏观归因（见 retrospective-module §2.4）。
3) 允许评价「新叙事是否兑现/被修正」；禁止买卖建议、高估低估结论、应在何时买入、仓位/目标价建议。
4) 禁止 Mermaid；图表只用已生成的 png，Markdown 嵌入绝对路径，每图一行图题。
5) 数字必须来自 files 证据包；缺数不编造。历史一致预期缺失时的 DCF 须保留「非当时一致预期，仅为利润路径近似」。
6) 周期股若出现「近端利润很高但 r=10% 隐含 L 极低」：解释为近端利润主导折现 + 市场对稳态中枢下修，勿写公式错误。
7) 篇幅：重大段写透（信息密度对齐隆基/煤炭/茅台级复盘）；次要脉冲进附录。中文。

【交付文件名】
{公司}_叙事行情复盘_{起点简}_{终点简}.md
（例：协鑫科技_叙事行情复盘_2014_2022.md）

【正文结构——必须按此顺序，标题层级与样板一致】

# {公司}（{代码}）{起点}–{终点} 叙事行情复盘：{一句话主题副标题}

## 复盘结论
- 开篇第一段用加粗给出：全区间个股累计涨跌、宽基累计涨跌、累计超额 pp；最大回撤；**alpha 是否高度集中于某一两段**（给出该段起止与个股%/超额 pp）。
- 随后 2–4 段：旧叙事主线 / 新叙事主线 / 尾声下修或兑现；点明「叙事切换型」还是「长兑现无 alpha」等资产类型。
- 若有案例镜像（如隆基上修 vs 本标的份额崩塌）：一段对照，可含同业辅线全窗口涨跌对比数字。
- 结论段不写投资建议。

## 数据与口径
### 价格、对标与估值口径
表格列：项目 | 口径（标的、前复权、宽基、样本区间与交易日数、市值币种、净利口径、DCF 假设与历史预期局限）。

### 关键年度与全区间表现
表：年份或全区间 | 个股% | 宽基% | 超额 pp（有 source 则保留证据包口径）。

### 复盘区间：业绩 × 股价（合图）
- 嵌入 **图2**（路径指向 {图目录} 下业绩×股价图）。
- 图题说明：左轴个股前复权归一化（窗口起点或 2014 初等=100）；右轴年报归母净利柱（红正绿负）；**本图不含宽基**。
- 一两句解读：利润与股价同步/背离的关键事实（如利润峰值年股价已回落）。

### 关键价格拐点
表：标签 | 日期 | 前复权收盘价（含段界高低点）。

## 叙事时间表与相对强度解读
### 叙事时间表
表：ID | 起止 | 标签（兑现/向上/向下/脉冲/宏观beta/接力） | 个股% | 宽基% | 超额pp | 一句话现象。

### 全区间相对走势（归一化）
- 嵌入 **图1**（个股 vs 宽基，全窗口归一化）。
- 图题：红/绿阴影含义（相对强弱）。

### 相对强度的主结论
至少三条独立判断（如下修期相对强度区间、主升修复时点、尾声锚从景气外推切回稳态等），每条有数字支撑。

## 分叙事段展开
对每一个重大段 Si（S1…Sn）：

## Si：{起止} —— {短标题}
1. **段首立即嵌入图Si**（该段个股 vs 宽基归一化）+ 一行图题。
2. **### 步骤2：隐含 L 表**  
   时点 | 市值 | E1/E2/E3（及是否近似） | r=10% L | L/E3 | 解读；可并列段首/段末。  
3. **### 步骤3：五问**（长文，勿缩成子弹）  
   按案例五问展开，表述可贴合本段，但须覆盖：  
   - 当时市场在交易什么 / 旧叙事是什么  
   - 为何涨或跌（截止时点可知事实）  
   - 叙事问题或关键变量（空间/份额/利润率/第二曲线/债务/政策）  
   - 为何持续或无法持续  
   - 本段本质（脉冲/兑现/上修/下修/beta）  
4. **### 步骤4：事后检验**  
   用段后路径与业绩标注兑现良好 / 过满 / 接力 / 脉冲无效；与步骤3信息集分离。

## 交易性/宏观脉冲附录
- 补充关键政策/流动性窗口表（可选）。
- 市值股本快照、配股/减债等融资与资产负债表旁证（若有）。
- 同业辅线窗口超额（若有）。
- 勿把附录写成第二套主升叙事。

## 步骤5：可迁移规律
至少 5–8 条，**结合本标的数字**，对齐但不空抄案例库，例如：  
全区间打平指数≠过程无叙事；超额窗口极短；上涨≠叙事变化（看相对宽基与 L）；政策更快一致预期；债务放大下修；困境反转弹性来自起点极低；周期股高位跌看稳态而非当年利润；技术第二曲线未必对冲行业周期 等。

## 免责
基于公开信息的历史解释框架；DCF 为情景反算；不构成投资建议。

【图表路径约定】
- 图1：{图目录}/…_full.png（或证据包写明的文件名）
- 图2：{图目录}/…_earn_price.png（仅业绩+股价）
- 图S1…Sn：{图目录}/…_S1.png …
若 files 中路径与上文不一致，以 files 实际 png 为准，但结构位次不得缺图。

【证据】
主要数字与事实来自：{证据包路径}
```

## 五、与旧「报告结构模板」条目的差异（终稿升级点）

| 旧模板 A 摘要 | 终稿固化后 |
|---------------|------------|
| 图非必须 | **图1 + 图2 + 每段图Si 默认必出** |
| 数据口径较粗 | 固定「年度表现表 → 图2 业绩×股价 → 拐点表」 |
| 分段含五问 | 段首先图再 L 表再五问再事后检验 |
| 未强调图2 不含宽基 | **图2 默认只业绩+股价**；宽基留给图1 与图Si |
| 结论较泛 | 开篇必须写清「累计接近指数但路径极陡 / alpha 集中段」 |

短窗模板 B 不在此文件扩展。
