# 穿透叙事分析--全面升级版

聚焦叙事分析，全面整合华源证券邹佩轩《穿透财报：读懂财报中的逻辑与现金》、《穿透估值：读懂估值中的共识与博弈》、《穿透叙事：寻找A股投资解析解》的分析框架。新版本经过了海量需求调研、大咖拜访与小范围内测，前后收到几十个宝贵建议，众人拾柴直击投研要害，Alpha派团队同步优化底层代码。跳出单个Skill边界，打造完整的方法论入口，贯通财报-估值-叙事-股价全链条，集个股叙事（DCF反算）、行业梳理、边际跟踪、历史复盘功能于一体，按照叙事框架整合所有我能想到的投研信息。

## 核心理念

《穿透叙事》的最核心思想即，我们不是给财报估值，我们是给叙事估值。决定股价高度的是叙事，决定股价涨跌的是叙事的变化。**叙事不是故事，而是一套基于逻辑的、可证伪、可量化的市场共识**：

1. DCF模型的本质就是一套叙事，证券交易的过程，就是一个人将一家公司目之所及的所有未来的现金流，按照一定的方式折叠到现在，然后打包卖给另一个人，只要另一个人认可这套叙事，交易就可以达成。
2. **无论是增速，还是增速的增速，都只是让市场相信终局叙事的一种手段，并不是估值的本源。**从三阶段增长模型来看，价值量占比最高的，是不再增长的稳态期，而决定稳态期价值的，是稳态期的高度。
3. **因此，在很多时候，所谓的“叙事”可以直接简化为公司的终局业绩**，也就是股价中许诺的未来究竟是怎样的，然后与我们认为的未来，以及市场未来认为的未来相比较，三者的差值决定了交易的得失。兑现叙事并不能获得超额收益，改变叙事才可以。判断股价涨跌之前，最重要的，是知道此时此刻股价隐含的叙事是什么。

## 关键创新点以及定义说明

1. **统一DCF反算框架：**默认基准年2025，稳态年2035；第4–10年（2029–2035）利润从E3**等比增长**至终局水平L，第**11**年起进入永续稳定期（**g=0）**；默认折现率**取r=8% / 10% / 12%**三档，用以刻画不同风险补偿假设。反算结果为"**当前市值在模型假设下隐含的终局利润L"**。
2. **L/E3与L/E0定义**：L/E3为隐含终局利润相对2028年一致预期的倍数；L/E0为隐含终局利润相对2025年归母利润的倍数。倍数>1表示隐含终局高于对应基准，<1表示低于对应基准，仅用于**描述增长强度**。
3. **券商目标价：**一律采用与现价**完全相同**的DCF框架反算其隐含终局L（市值=目标价×总股本），不做PE/PEG/SOTP等替代重估。
4. **关键词热度口径**：分母=当月公司相关文档数；分子=命中该叙事同义词簇的文档数；渗透率=分子/分母；Z=(近月渗透率−历史均值)/历史标准差。

> ⚠️同时生成配套excel，可编辑，方便投资者正算目标价。
>
