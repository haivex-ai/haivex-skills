# AI 新材料市场空间测算（TAM）建模与展示规范

本技能用于搭建或维护「AI 算力链 → 电子新材料」自底向上市场空间/利润空间测算模型，并强制执行一套可追溯、可审计的 Excel 展示规范。核心价值在于：**任何一个数字都能一眼区分"有来源"还是"测算值"，且测算值的计算过程通过 Excel 公式完全可见、可联动。**

## 一、模型核心方法论（自底向上五层链路）

测算遵循统一链路，逐层联动（修改上游自动重算下游）：

```
出货量(万颗) ── 单颗材料价值量($/颗) ──► 材料市场空间(亿美元) ──► 材料利润空间(亿美元)
   Sheet2          Sheet1                      Sheet4              Sheet6(×毛利率)
                (引用关键参数锚点P/Q/R区)
```

核心公式（写进表头说明行）：
- **材料市场空间** = Σ 各芯片型号[ 出货量(万颗) × 单颗材料价值量($/颗) ] ÷ 10000 = 亿美元
- **材料利润空间** = 材料市场空间 × 对应芯片/环节毛利率
- **光模块/光纤独立测算**（机柜口径，非单颗芯片口径）= 机柜出货量 × 单机柜光模块数 × 光模块 ASP
- **CAGR** = `=IFERROR((末年/首年)^(1/年数)-1,"")`

标准 Sheet 组织（按既有模型 v4）：
1. `单颗材料价值量假设` — 各芯片平台×各材料的 $/颗（核心假设层，含右侧关键参数锚点区 + 文字版测算依据说明）
2. `出货量汇总(万颗)` — 各芯片型号分年出货量（用户/机构提供）
3. `材料空间测算(亿美元)` — 纯公式，Σ(出货量×单颗价值量)÷10000
4. `分平台材料空间明细` — 按平台拆解的明细
5. `材料利润空间测算` — 毛利率假设 + 空间×毛利率
6. `光模块市场空间测算` — 机柜口径独立测算
7. `AI芯片市场空间测算` — 芯片本体空间
8. `Sources` — 来源清单（编号、标题、详情、范围、获取日期）

## 二、强制展示规范（本技能的核心，务必逐条执行）

### 规范 1：单元格底色区分数据性质（最重要）
| 底色 | RGB | 含义 | 适用 |
| --- | --- | --- | --- |
| **黄色** | `FFFFFF00` | **有明确机构/财报数据来源** | 直接取自研报/财报/用户数据的原始值；关键参数锚点 |
| 白色（无填充） | 无 | **基于折算比例的测算值**，计算过程见公式 | 所有 `=...` 推算单元格 |
| 米黄 | `FFFFF8E1` | 假设参数 / 待调区 | 可调假设输入区 |
| 深蓝 | `FF194F90` | 表头（配白字） | 列标题行 |
| 浅蓝 | `FFD6E4F0` / `FFDCE6F1` | 分类标题 / 小计 / 结果行 | 分组行、合计行、跨表引用结果 |

> 一句话原则：**黄 = 抄来的（有来源），白 = 算出来的（有公式），米黄 = 可调假设。**

### 规范 2：每个 Sheet 顶部加图例说明行
- A1 = 标题（含单位，如"…（美元/颗）"/"…（亿美元）"）
- A2 = 图例/测算逻辑，统一格式：
  - 假设/价值量表：`★ 黄色底色 = 有明确机构数据来源 ｜ 白色底色 = 基于折算比例的测算值（公式可见计算过程）`
  - 空间测算表：`测算逻辑：∑ 各型号[出货量(万颗) × 单颗材料价值量($/颗)] ÷ 10000 = 市场空间(亿美元)`
  - 利润表：`测算逻辑：各平台材料市场空间 × 对应芯片毛利率 = 材料利润空间 ｜ ★黄色=有官方财报来源的毛利率`

### 规范 3：来源标注落到单元格批注 + 独立 Sources 表
- 每个黄色（有来源）单元格添加 **cell comment**，内容格式：`[来源:N] 来源标题`（N 对应 Sources 表编号；多来源示例：`[来源:2,11] 来源标题`）。编号必须已在Sources表登记。
- 紧邻黄色锚点值的单元格可写简短文本标记 `来源:N`（如锚点区 R 列）。
- `Sources` 表固定 5 列：`编号 | 来源标题 | 来源详情 | 数据范围 | 获取日期`。每条来源唯一编号，全表批注引用此编号。

### 规范 4：测算值必须用"可见公式"，禁止硬编码计算结果
- 折算/推导单元格一律写 Excel 公式（如 `=Q4*Q8/Q7`、`=E6*0.30*0.42`、`=ROUND(O6*0.65,0)`），使读者能直接看到计算过程与引用来源。
- 跨表汇总用显式逐项相加或 `SUMPRODUCT`，保持与出货量/价值量表的实时联动。
- 折算系数（如 ASIC 按 NVIDIA×0.9、CCL 占 PCB 30%、铜箔/树脂/玻纤 42%/26%/19%）应来自锚点区参数或在批注/说明区写明依据。

### 规范 5：关键参数锚点区（集中放"有来源的原始数"）
- 在假设表右侧（如 P/Q/R 列）建立"关键参数锚点"区：P 列=参数名、Q 列=数值(黄色)、R 列=`来源:N`。
- 所有单颗价值量公式**引用锚点**而非散落硬编码，便于统一更新与溯源（例：`B200 GPU = Q4*Q8/Q7` = 机架总价×GPU占比÷每机架GPU数）。

### 规范 6：前提假设写清楚（文字说明区）
- 在假设表底部用 `【测算依据详细说明】` 段落，分平台/分材料逐条写明：原始来源是什么、单颗如何由机架级拆解（÷72 / ÷64）、无直接来源处的折算逻辑与溢价系数假设（如 R300 在 R200 基础上整体溢价 18%）。
- 利润表中毛利率假设需注明：口径（Non-GAAP/GAAP/整机）、数据来源、报告期。

## 三、执行工作流

### 场景 A：从零搭建新模型
1. 确认范围：覆盖哪些芯片平台（NVIDIA/ASIC/AMD/国产）、哪些材料环节、测算年份、单位（亿美元）。
2. 收集原始数据并编号录入 `Sources`：BOM 拆解、单颗/机架价值量、出货量、毛利率等（用 `search_paipai`/`search_global_data`/`doc_searcher` 取数，原始值标黄）。
3. 用 `scripts/build_tam_model.py` 生成符合规范的标准骨架（含 8 个 Sheet、配色、图例、Sources 表、关键参数锚点区），或在其基础上 `invoke_tool`(excel-js-operations) / openpyxl 填充。
4. 填入出货量与锚点参数（黄色），单颗价值量与空间/利润全部写公式（白色），逐一加来源批注。
5. 用 `scripts/check_tam_format.py` 校验规范合规性。骨架是待填模板，须完成来源、输入和公式填充后再验收；空骨架不等同于合规成品。

### 场景 B：更新/扩展既有模型
1. 读取既有 Excel（openpyxl，`data_only=False` 看公式），定位锚点区与 Sources 表。
2. 新增来源 → 先在 Sources 表追加编号；新增原始数据单元格标黄 + 加批注；新增测算单元格写公式（白色）。
3. 改假设只改锚点区/出货量黄色输入，下游公式自动联动，不要去改公式单元格的值。
4. 校验：运行 `scripts/check_tam_format.py`。

### 场景 C：仅校验/体检既有模型是否合规
直接运行 `scripts/check_tam_format.py <xlsx路径>`，报告：硬编码疑似测算值（应为公式却是常量）、有来源但无批注、Sources 表缺失列、缺图例行等问题。

## 四、工具与取数指引（PaiWork 环境）
- 海外 BOM/价值量/出货量/毛利率（大摩、UBS、Corning、台积电等）：优先 `search_global_data`（需先 `read_skill('search-global-data')`）、`search_paipai`(sources=['foreign_report','report','comment'])、必要时 `delegate_to_agent('doc_searcher', ...)` 穷举研报。
- A 股材料公司毛利率/财务：`quick_fetch_stock_financials` 或 `delegate_to_agent('data_analyst', ...)`。
- 中间取数结果用各工具 `save_as` 存到 `tmp/{session_id}/`，不要 `write_file` 手搓中间数据。
- **任何写入 Excel 的原始外部数据都必须在 Sources 表登记编号并在单元格加 `[来源:N] 来源标题` 批注。**

## 校验结果与限制

脚本退出码：0=未发现已实现检查的问题，1=发现待整改项，2=调用参数错误。每个黄色格都必须有合法批注，编号须在Sources登记；来源只写在数值文本中不算合格。

硬编码检测是保守启发式：检查标准测算表的年度/结果列，以及以公式为主的行列；黄色原始输入和米黄假设区不计为硬编码测算结果。它不能证明任意布局都没有硬编码，也不重算公式或判断经济假设合理性。
