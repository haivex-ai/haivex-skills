# data_analyst 查询模板（已冒烟验证）

将 `{T}`、`{T_start}`（约 T 往前 35 个自然日以覆盖 20+ 交易日）、`{session}` 替换为实际值。  
路径统一：`tmp/{session}/table/...`

## 关键结论（2026-07 验证）

| 路径 | 结论 |
|------|------|
| **主路径** | **基金份额变动表**，统计区间=**日频（996）**，字段 **资金净流入（单位：元）** → `/1e8` 得亿元 |
| 辅路径 | 同表：期末份额、基金份额变化（份）、平均成交价、收盘价格、成交额（元） |
| 日行情表 | 有收盘/涨跌/成交，**累计资金流向常为空**，不作净流入主源 |
| 宽基筛选 | 标签：**基金类型=宽基** + **资产类别=权益**（可再加规模=大盘股收窄） |
| 缺失行 | 个别基金个别日「资金净流入+份额变化」双空 → 该行跳过或标注缺失，勿填 0 |

**禁止在 instruction 中堆砌英文表名强迫 DA**；用中文业务名「基金份额变动日频」「资金净流入」即可（下方模板已按此书写）。

## A. 核心池日度资金流（主表，必跑）

```text
请在基金域使用「基金份额变动」日频数据（统计区间为日频），查询下列 ETF 从 {T_start} 至 {T}（含）的记录：
510300.SH 华泰柏瑞沪深300ETF、
510310.SH 易方达沪深300ETF、
510330.SH 华夏沪深300ETF、
159919.SZ 嘉实沪深300ETF、
510050.SH 华夏上证50ETF、
510500.SH 南方中证500ETF、
512100.SH 南方中证1000ETF、
159845.SZ 华夏中证1000ETF、
159915.SZ 易方达创业板ETF、
159949.SZ 华安创业板50ETF、
588000.SH 华夏上证科创板50成份ETF、
588080.SH 易方达上证科创板50ETF。

若某代码匹配不到，尝试不带后缀或库内主代码，并在结果中标注实际代码。

必须返回字段：
- 交易日期或截止日期
- 基金代码、基金简称
- 期末份额、基金份额变化（份）
- 平均成交价、收盘价格
- 成交额（元）
- 资金净流入（元）——这是主字段
- 若有：流通份额变化、资金累计流入

加工列（在导出 CSV 时写好）：
- cash_flow_yi = 资金净流入 / 100000000（亿元）
- 若资金净流入为空且基金份额变化与价格非空：
  cash_flow_yi = 基金份额变化 × 平均成交价 / 1e8；
  均价空则用收盘价；flow_source 标 share_times_price
- 若双空：仍输出行，cash_flow_yi 置空，flow_source=missing（不要当成 0）
- amount_yi = 成交额 / 1e8
- pct_chg 若本表无，可左联 ETF 日行情涨跌幅

按交易日期、基金代码升序。
完整结果保存到 tmp/{session}/table/nt_core_etf_flow.csv。
回复：行数、日期范围、最新日、最新日核心池合计 cash_flow_yi（仅对非空求和）、非空只数、列名、前5行样例。禁止倾倒全表。
```

## E. 失败重试顺序

1. 核心池资金净流入全空 → 确认统计区间=日频；检查是否误查了季报份额表。  
2. 仍空 → 用「基金份额变化×平均成交价」估算。  
3. 代码无数据 → 去后缀 / 换同类龙头（至少保留 510300、510050、159915 冒烟）。  
4. 宽基标签 0 行 → 名称/指数白名单降级。  
5. 单日单券 |净流入| > 500 亿 → 复核单位是否未从「元」换算。  
6. 北向数字异常偏大（如单日数千亿）→ 多半是成交额，丢弃或改标，不进国家队叙事。

## F. 可复用一句话模板（冒烟用）

```text
请在基金域优先使用基金份额变动日频数据，筛选统计区间为日频，查询指定 ETF 最近 N 个有数据交易日的资金净流入（元）、期末份额、份额变化、成交额、收盘价；若资金净流入为空，则用份额变化×均价（均价空则×收盘价）估算，并统一 /1e8 为亿元输出。
```
