# 输出模板

文件名：`国家队资金跟踪_{YYYYMMDD}.md`  
标题日期 = 基准日 T（已收盘交易日）。

```markdown
# 国家队资金日度跟踪（代理口径）

**基准日 T**：YYYY-MM-DD（已收盘）  
**主口径**：核心宽基/稳市相关 ETF 日度净申购代理（≠国家队真实成交单）  
**数据**：实际使用的数据来源（需注明） + 公开资讯

---

## 一、结论摘要

（≤120 字）T 日核心池代理净流入 **+X.X 亿元**（近5日累计 **+Y.Y 亿**）。  
结构：大盘/成长/中小盘各自一句话。  
标签：**强净申购 / 明显净申购 / 中性 / 明显净赎回** + 与指数涨跌是否同向。  
若有汇金/国新等公开动作，一句带过。

---

## 二、分池仪表盘（T 日）

| 分池 | T日净流入(亿) | 近5日累计(亿) | 信号 |
|------|---------------|---------------|------|
| 大盘压舱 | | | |
| 成长稳估 | | | |
| 中小盘托底 | | | |
| **核心池合计** | | | |

---

## 三、核心池个券（T 日）

### 净流入 Top

| 代码 | 简称 | 净流入(亿) | 成交额(亿) | 涨跌% | 备注 |
|------|------|------------|------------|-------|------|

### 净流出 Top（若有）

| 代码 | 简称 | 净流入(亿) | 成交额(亿) | 涨跌% | 备注 |
|------|------|------------|------------|-------|------|

---

## 四、趋势（核心池合计）

| 日期 | 核心池净流入(亿) | 方向 |
|------|------------------|------|
| …近10日… | | |

（可附：是否连续 N 日流入/脉冲后回吐）

---

## 五、宽基全市场结构（L2，若已取）

- 权益宽基 ETF 合计净流入：**Z 亿**  
- 分指数：300 / 50 / 500 / 1000 / 创业板 / 科创 …  
- 与核心池差异：一句话（核心池是否代表性足够）

---

## 六、市场语境

|-----------|-----|-------|
| 上证指数 | | |

| 创业板指 | | |
| 科创50 | | |
| 北向净流入(对照) | | |

北向**仅对照**，不计入国家队代理。

---

## 七、公开事件（L3）

- 无：近两周未见汇金/证金/国新/诚通增量公开动作（或不适用）。  
- 有：主体 | 动作 | 金额/范围 | 来源日期。

---

## 八、口径与局限（固定保留）

1. 日度数字为 **ETF 净申购代理**，包含全部市场参与者，不能等同汇金/证金委托成交。  
2. 急跌日多只核心 300/科创 ETF 共振大额净申购时，稳市资金叙事概率上升，仍非实锤。  
3. 季报持仓验证滞后一个季度，不与日频加总勾稽。  
4. 字段缺失时可能使用「份额差×价」估算，见明细 `flow_source`。

---

## 九、风险提示

代理误读、份额数据延迟或单位错误、政策工具切换导致监控池失效、把北向/游资误并入口径。
```
