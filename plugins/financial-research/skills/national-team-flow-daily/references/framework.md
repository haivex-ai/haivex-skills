# 国家队资金日度跟踪 — 分析框架

## 1. 为什么用 ETF 代理

公开信息显示，近年稳市资金（中央汇金及其资管计划、证金相关通道、国新/诚通等）大规模入市的主路径之一是**申购宽基及部分主题 ETF**，而非逐笔披露的个股扫货。日频可观测、可复算的是：

\[
\text{代理净流入}_{i,t} \approx \Delta \text{Share}_{i,t} \times P_{i,t}
\]

或直接使用库内已算好的 **资金净流入 / CASH_FLOW**（优先）。

该代理的含义是「这些被盯盘的工具上，**全市场**申购赎回净额」，其中可能包含国家队，也可能包含机构配置、套利与散户。

## 2. 三层监控

| 层级 | 内容 | 频率 | 置信度 |
|------|------|------|--------|
| L1 核心池 | 历史国家队重仓、媒体「护盘」高频点名的 300/50/500/1000/创业板/科创等龙头 ETF | 日 | 中高（信号灵敏，噪声仍在） |
| L2 宽基全市场 | 全部权益宽基 ETF 合计与分指数结构 | 日 | 中（结构比绝对额更有用） |
| L3 事件 | 汇金/证金/国新/诚通/险资公告与权威报道 | 事件驱动 | 高（定性），金额依赖报道质量 |
| L4 季报 | 基金十大持有人中国家队名单变动 | 季 | 高（滞后） |

## 3. 信号解读启发式

### 3.1 方向与量级（核心池合计，可按市况微调）

| 单日核心池净流入 | 初步标签 | 备注 |
|------------------|----------|------|
| ≥ +80 亿 | 强净申购 | 急跌日+多只 300ETF 共振 → 稳市概率↑ |
| +50 ~ +80 亿 | 明显净申购 | 结合指数与是否尾盘放量 |
| +15 ~ +50 亿 | 温和净申购 | 常态配置也可能达到 |
| -15 ~ +15 亿 | 中性 | 勿过度解读 |
| -30 ~ -15 亿 | 温和净赎回 | |
| ≤ -30 亿 | 明显净赎回 | 可能是止盈/再平衡，不一定是「国家队撤出」 |

连续 3 日以上同向，比单日脉冲更有趋势意义。

### 3.2 结构

- **大盘压舱层**（上证50、沪深300）：传统托底盘。  
- **成长层**（创业板指、科创50、科创芯片等）：稳市工具箱扩容后的第二支柱；成长层大额净申购更像「稳估值/引导风险偏好」。  
- **中小盘层**（中证500/1000）：流动性托底特征。  

「仅大盘进、成长出」偏防御；「三层同进」偏全面稳市或系统性吸筹。

### 3.3 与价格的配合

| 价格 | 代理流入 | 常见读法 |
|------|----------|----------|
| 大跌 | 大额净申购 | 护盘/逢低接（提高国家队叙事权重） |
| 大涨 | 大额净申购 | 趋势增强或 FOMO，国家队叙事权重↓ |
| 大跌 | 大额净赎回 | 杠杆/赎回负反馈，忌说国家队护盘成功 |
| 平盘 | 脉冲流入 | 关注是否预报或尾盘异动 |

## 4. 明确不是什么

- **不是**沪深港通北向（外资）。  
- **不是**游资龙虎榜、也不是普通「主力净额」模型。  
- **不是**社融/财政资金日报。  
- **不能**把 L1 净流入直接加总到「汇金持仓市值」或与 L4 季报数字强行勾稽成连续曲线。

## 5. 输出用词规范

| 推荐 | 避免 |
|------|------|
| 核心宽基ETF代理净流入 +XX 亿 | 国家队今日买入 XX 亿（无证据时） |
| 疑似稳市资金活跃（急跌+共振） | 确认是汇金操作 |
| 公开报道称国新/诚通增持 | 内部消息 |

## 6. 缺口与降级

1. 份额日频缺字段 → 用昨今流通份额差 × 收盘价。  
2. 标签「宽基」召回不全 → 用跟踪指数白名单（见 watchlist）强制纳入。  
3. 货币 ETF 混入 → 资产类别必须权益/股票，剔除货币、债基。  
4. 盘中无完整份额 → 报告标明「仅用已收盘 T，未用盘中预估」。
