# 国家队资金日度跟踪

## 核心认知（必须先说清）

库内**没有**「中央汇金/证金当日净买入金额」的直读字段。本技能采用业界通用的**日度代理口径**：

1. **主代理（日频）**：国家队历史重仓、稳市中常被盯的**核心宽基/稳市相关 ETF** 的份额变动与资金净流入。  
2. **结构代理（日频）**：权益**宽基 ETF 全市场**净流入与分指数层（大盘/成长/中小盘）结构。  
3. **事件代理（不定期）**：汇金、证金、国新、诚通、险资自购/增持等**公开新闻与公告**。  
4. **季频校验（可选）**：基金季报十大持有人中的汇金/证金等持股变动（只能验证季度，不能替代日频）。

输出中必须写明：**代理估算 ≠ 国家队真实成交流水**；普通机构与散户同样会申赎这些 ETF。

口径与名单细节见：

- [references/framework.md](references/framework.md) — 代理逻辑、信号解读、局限  
- [references/etf_watchlist.md](references/etf_watchlist.md) — 核心/扩展监控池  
- [references/data_queries.md](references/data_queries.md) — `data_analyst` instruction 模板  
- [references/output_template.md](references/output_template.md) — 报告骨架  

加工脚本：`scripts/summarize_nt_flow.py`（聚合日表、分池、阈值标记）。

## 执行流程

### Step 0：参数

| 参数 | 默认 | 说明 |
|------|------|------|
| 基准日 T | 最新**已收盘**交易日 | 盘中跑则用上一已收盘日；用户指定日须为交易日 |
| 回看窗口 | 近 **20** 个交易日 | 用户说「本周/近5日」则缩短；趋势图最少 10 日 |
| 监控池 | 核心池（见 watchlist） | 用户可指定「只看沪深300」「含科技ETF」等 |
| 输出深度 | 标准日报 | `简报`仅结论+表；`深度`加舆情与结构解读 |

### Step 1：锚定交易日

```
trading_calendar(market="a_share")
```

取 `最新已收盘交易日` 为 **T**。用户指定历史日时校验是否为交易日。

### Step 2：并行取数（data_analyst）

同一轮尽量并行 2–3 个委托（**instruction 全文与已验证字段见** `data_queries.md`）：

**取数硬约束（冒烟已验证，勿走错表）**

1. **净流入主表 = 基金份额变动「日频」**（统计区间日频/996），字段 **资金净流入，单位元** → 亿元须 `/1e8`。  
2. **不要**用 ETF 日行情里的「累计资金流向」当主源（常全空）。  
3. 净流入空时：用 **基金份额变化（份）× 均价/收盘价 /1e8**；双空则标记 missing，**禁止当 0**。  
4. 宽基筛选：标签 **基金类型=宽基 + 资产类别=权益**；0 行再降级为指数名称白名单。  
5. 北向必须是净流入；若库返回像单日数千亿，多半是成交额，丢弃或改标，不并入口径。

**A. 核心池日度资金流**（主表）  
- 核心池代码清单见 `etf_watchlist.md`  
- 字段：日期、代码、简称、期末份额、份额变化、资金净流入(元)、均价/收盘、成交额、涨跌幅  
- 窗口：T 往前 ≥20 个交易日  
- 落盘：`tmp/{session_id}/table/nt_core_etf_flow.csv`

**B. 宽基权益 ETF 全市场结构（T 当日 + 近5日累计）**  
- 标签：基金类型=宽基 + 资产类别=权益；剔除货基/债基/商品/QDII  
- 输出：全市场宽基合计净流入；分指数层；Top 流入/流出  
- 落盘：`tmp/{session_id}/table/nt_broad_etf_rank.csv`

**C. 市场语境**  
- 上证指数、沪深300、创业板指、科创50：T 日收盘与涨跌幅  
- 北向资金近5日**净流入**（仅对照）  
- 落盘：`tmp/{session_id}/table/nt_market_context.csv`

**D. 公开事件（与 A/B/C 并行，主 Agent 直接搜）**

```
search_paipai(
  queries=["中央汇金 增持 ETF", "证金公司 稳市", "国新 诚通 增持", "宽基ETF 净流入 国家队"],
  sources=["ann","comment","report"],
  start_time=T往前约14天, end_time=T或今天
)
```

必要时 `search_web` 补「国新/诚通回购增持再贷款、险资入市」等高时效线索；金额以可核验报道为准。

### Step 3：脚本汇总

```bash
python3 /workspace/skills/user/national-team-flow-daily/scripts/summarize_nt_flow.py \
  --core tmp/{session_id}/table/nt_core_etf_flow.csv \
  --broad tmp/{session_id}/table/nt_broad_etf_rank.csv \
  --market tmp/{session_id}/table/nt_market_context.csv \
  --trade-date {T} \
  --outdir tmp/{session_id}/table \
  --prefix nt_flow
```

脚本产出（CSV + stdout 摘要）：

- `nt_flow_daily_summary.csv`：T 日核心池合计、分池合计、近5日累计  
- `nt_flow_core_detail_T.csv`：核心池个券明细与阈值标记  
- `nt_flow_series.csv`：核心池合计日序列（回看窗口）

阈值默认（可在框架中调整，改脚本参数即可）：

- 单日核心池合计净流入 **≥ +50 亿** → 明显净申购信号  
- 单日核心池合计 **≤ -30 亿** → 明显净赎回信号  
- 单只核心券净流入 **≥ +20 亿** 或成交额较近20日均量显著放大 → 个券异动  

### Step 4：写报告并交付

默认路径：

`tmp/{session_id}/outputs/国家队资金跟踪_{YYYYMMDD}.md`

（仅当用户明确要求存工作区时写入 `tree/`。）

结构严格按 [output_template.md](references/output_template.md)：

1. **结论先行**（≤120 字）：T 日核心池净流入方向与量级 + 一句话解读（护盘/回笼/中性观望）  
2. **表1 分池仪表盘**（大盘压舱 / 成长 / 中小盘 / 合计）  
3. **表2 核心池个券 Top 流入与流出**  
4. **表3 近5–20 日合计趋势**（是否连续流入/脉冲后回吐）  
5. **市场语境**：指数涨跌、北向对照、成交是否尾盘放量（有舆情则写）  
6. **公开事件**：汇金/国新/诚通/险资等（无则写「近两周无增量公开动作」）  
7. **口径与局限**（固定短段，不可删）  
8. **风险提示**

短问（「今天国家队进了吗」）可用 `answer` 直出结论 + 核心表；标准/深度用 `write_file` 落 md 后 `answer` 附链接。  
材料很多、需要长篇综合时可用 `analyst_report`，`instruction` 只写目标与结构，证据走 `files`。

### Step 5（可选）：季频交叉验证

用户问「汇金到底买了哪些/持仓验证」时：

```
data_analyst: 十大股东/基金十大持有人中，股东名称含
「中央汇金」「中国证券金融」「中证金融」「汇金资管」「国新投资」「中国诚通」等，
取最近两个报告期，汇总持仓市值/份额变动。
```

季频结果**单独成节**，勿与日频净流入加总成同一数字。

## 解读纪律

1. **金额永远带口径标签**：如「核心宽基ETF代理净流入 +XX 亿」，禁止写成未加引号的「国家队买入 XX 亿」。  
2. **同向未必是国家队**：单边慢牛里宽基净申购可能是公募配置；优先在**急跌、尾盘异动、多只核心300ETF同时大额净申购**时提高「稳市资金」概率表述。  
3. **分池读结构**：仅 300/50 大进而成长失血 → 偏防御托底；300+科创/创业板共振 → 更像全面稳估值。  
4. **北向、两融、龙虎榜**只作语境，不得并入口径合计。  
5. **数据缺失**：某字段全空则按 `data_queries.md` 降级并在报告「缺口」写明；单日单券 |净流入|>500 亿先怀疑单位未从元换算；北向异常偏大先怀疑误取成交额。

## 定时任务（可选）

用户要求「每天收盘后推送」时：用 `cron` 设 A 股交易日 18:30 后或 21:00 后执行本技能（给入库留时间），`payload.message` 保持用户原话如「跟踪今日国家队资金流入流出并做总结」。可复用本 SKILL 流程，勿在 cron 里塞私有持仓。
