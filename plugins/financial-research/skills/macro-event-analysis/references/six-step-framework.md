# 六步分析框架：详细执行指引

本文件为每个分析步骤提供具体的执行方法、输出模板和质量检查清单。

## 步骤 1：关键变量 (Key Variables)

### 目标

从宏观事件中提炼出 **3–7个** 真正驱动市场定价的核心变量，建立可跟踪的"仪表盘"。

### 执行方法

1. **事件拆解**：将宏观事件拆为"政策/冲击本身 → 实体经济传导 → 金融市场反映"三层
2. **变量筛选四问**：对每个候选变量逐一检验——
   - 该变量变动 10%，目标资产是否变动 >2%？（**影响力**）
   - 该变量能否在 48h 内获取可靠读数？（**可观测性**）
   - 该变量是否独立于已选变量？（**非冗余**）
   - 市场当前是否正在定价该变量？（**市场关注度**）

3. **分类标注**：将入选变量按以下维度分类——

| 维度     | 分类                           | 说明                             |
| -------- | ------------------------------ | -------------------------------- |
| 时序属性 | 先行 / 同步 / 滞后             | 相对于资产价格反应的领先滞后关系 |
| 可控性   | 政策可控 / 市场内生 / 外生冲击 | 判断变量是否可被政策干预         |
| 数据频率 | 实时 / 日频 / 周频 / 月频      | 决定跟踪节奏                     |

4. **当前读数**：标注每个变量的最新值、近期趋势方向（↑↓→）、关键阈值或市场一致预期

### 输出模板

```markdown
### 1. 关键变量

| #   | 变量名称 | 时序属性 | 可控性   | 频率 | 当前读数 | 趋势 | 关键阈值 | 数据来源 |
| --- | -------- | -------- | -------- | ---- | -------- | ---- | -------- | -------- |
| 1   | xxx      | 先行     | 政策可控 | 日频 | xx       | ↑    | xx       | xxx      |
| 2   | ...      | ...      | ...      | ...  | ...      | ...  | ...      | ...      |

**核心矛盾**：当前市场定价的核心矛盾是 与 之间的 。
```

### 信息收集指引

- `search_edb` / `search_global_data`：获取利率、汇率、商品价格、PMI 等宏观指标最新读数；国内宏观用 `search_edb`、境内指数点位用 `delegate_to_agent(agent_type="data_analyst", ...)` 的 `指数相关` 数据域，海外利率、汇率、商品等优先用 `search_global_data`
- `search_paipai` (sources: report, comment)：搜索" 关键变量/核心矛盾/定价因子"
- `search_web`：搜索 "key variables / drivers / what matters"

### 质量检查

- 变量数量 3–7 个，不多不少
- 每个变量都有当前读数和数据来源
- 已标注先行/同步/滞后属性
- 已识别当前的核心矛盾

## 步骤 2：变量传导路径 (Transmission Mechanism)

### 目标

绘制从"事件冲击"到"资产价格变动"的完整因果链，标注每一跳的传导时滞和放大/衰减机制。

### 执行方法

1. **链式拆解**：按"事件 → 一阶效应 → 二阶效应 → 资产定价"逐层展开
   - **一阶效应**：事件直接改变的经济变量（如关税→进口成本↑）
   - **二阶效应**：一阶变量引发的连锁反应（如进口成本↑→CPI↑→加息预期↑）
   - **资产定价**：最终反映到哪些资产的哪个定价因子（如加息预期↑→长端利率↑→成长股承压）

2. **时滞标注**：每条传导链标注时间维度——

| 时间窗口    | 典型传导                           |
| ----------- | ---------------------------------- |
| T+0 即期    | 情绪冲击、汇率、期货               |
| T+1W 一周   | 资金流重新配置、期权隐含波动率     |
| T+1M 一月   | 经济数据开始反映、企业盈利预期调整 |
| T+1Q 一季度 | 实体经济传导完成、财报验证         |
| T+1Y 一年   | 结构性影响显现、产业链重构         |

3. **放大/衰减机制**：识别传导链中的关键节点——
   - **放大器**：杠杆效应、预期自我实现、流动性螺旋、政策叠加
   - **衰减器**：政策对冲、库存缓冲、替代效应、市场已充分定价
   - **非线性节点**：存在阈值效应的环节（如汇率破 7、油价破 100）

4. **交叉传导**：标注不同传导链之间的交叉影响和反馈环路

### 输出模板

```markdown
### 2. 变量传导路径

#### 主传导链

事件：
│
├─→ 【一阶·即期】 ──→
│ │
│ └─→ 【二阶·1周–1月】 ──→
│ │
│ └─→ 【三阶·1月–1季度】 ──→
│
└─→ 【平行链】 ──→ ...

#### 传导时滞矩阵

| 传导环节 | 时滞 | 放大/衰减        | 非线性阈值   | 当前所处阶段 |
| -------- | ---- | ---------------- | ------------ | ------------ |
| A → B    | 即期 | 放大（杠杆）     | 无           | 已发生       |
| B → C    | 1周  | 衰减（政策对冲） | B > X 时加速 | 进行中       |

#### 反馈环路
```

### 信息收集指引

- `search_paipai` (sources: report)：搜索" 传导路径/传导机制/影响链条"
- `search_web`：搜索 "transmission mechanism / spillover / second-order effects"
- `plot`：**必须生成一张传导路径信息图**，直观展示因果链

### 质量检查

- 覆盖至少2条独立传导链
- 每条链标注了时滞
- 已识别放大/衰减机制
- 已标注"当前所处阶段"
- 已生成传导路径可视化图

## 步骤 3：历史类似案例 (Historical Analogues)

### 目标

找到 **2–4个** 历史可比案例，提取资产表现的统计规律，并明确本次与历史的关键异同。

### 执行方法

1. **案例筛选标准**（至少满足2条）：
   - 事件性质相似（同类型政策/冲击）
   - 经济周期位置相似（扩张/衰退/滞胀）
   - 市场结构相似（估值分位/仓位水平/流动性环境）
   - 传导机制相似（影响同类资产、同方向）

2. **数据提取**：对每个案例收集——
   - 事件发生后 T+1D / T+1W / T+1M / T+3M / T+6M 的主要资产回报
   - 波动率变化（VIX 或等价指标）
   - 政策响应时间线
   - 市场从冲击到恢复的时间

3. **异同分析**：制作"本次 vs 历史"对比矩阵，重点标注——
   - **相似之处**：支持类比推断的因素
   - **关键差异**：可能导致本次走势偏离历史的因素
   - **差异的方向性**：该差异使本次影响更大还是更小

### 输出模板

```markdown
### 3. 历史类似案例

#### 案例概览

| 案例  | 时间    | 事件概述 | 相似度 | 关键相似点 | 关键差异 |
| ----- | ------- | -------- | ------ | ---------- | -------- |
| 案例1 | YYYY-MM | xxx      | ★★★★☆  | ...        | ...      |
| 案例2 | YYYY-MM | xxx      | ★★★☆☆  | ...        | ...      |

#### 资产表现回溯

| 资产    | 案例1 T+1W | 案例1 T+1M | 案例2 T+1W | 案例2 T+1M | 中位数 |
| ------- | ---------- | ---------- | ---------- | ---------- | ------ |
| 标普500 | -3.2%      | +1.5%      | -5.1%      | -2.3%      | ...    |
| 10Y美债 | ...        | ...        | ...        | ...        | ...    |

#### 本次 vs 历史的关键差异

| 维度     | 历史案例 | 本次     | 差异影响方向 |
| -------- | -------- | -------- | ------------ |
| 经济周期 | 扩张中期 | 扩张晚期 | 冲击更大     |
| 政策空间 | 利率 x%  | 利率 y%  | 对冲能力更弱 |

#### 历史规律总结

基于历史案例， 在类似事件后的典型表现为：。
但本次因 ，预计 。
```

### 信息收集指引

- `search_paipai` (sources: report, foreign_report)：搜索" 历史复盘/历史案例/回顾"
- `search_web`：搜索 " historical precedent / analogue / past episodes"
- `search_edb` / `search_global_data` / `delegate_to_agent(data_analyst)`：获取历史案例期间的资产价格数据；境内指数收盘价走 `指数相关` 数据域，A股个股历史行情走 `个股相关` 数据域，港股/美股/海外指数/外汇/商品等用 `search_global_data`。DA 最终取数统一查询，并返回完整结果
- `plot`：**必须生成一张历史案例资产表现对比图**

### 质量检查

- 案例数量 2–4 个
- 每个案例有具体的资产回报数据（非定性描述）
- 已制作本次 vs 历史的差异矩阵
- 已明确差异的方向性影响
- 已生成历史对比可视化图

## 步骤 4：可能市场结构 / 情景推演 (Scenario Analysis)

### 目标

基于关键变量的不同组合，推演 **2–3个** 情景，给出各情景的概率权重和资产方向判断。

### 执行方法

1. **情景构建**：基于步骤1中的关键变量，设定不同取值组合——

| 情景类型     | 构建逻辑                                               |
| ------------ | ------------------------------------------------------ |
| **基准情景** | 关键变量沿当前趋势线性外推，市场一致预期兑现           |
| **乐观情景** | 正面催化剂出现（政策超预期宽松、冲突缓和、数据超预期） |
| **悲观情景** | 负面尾部风险兑现（冲击升级、政策失误、流动性危机）     |

2. **概率赋权**：
   - 基于历史基准率 + 当前信息更新
   - 三个情景概率之和 = 100%
   - 标注概率的置信度（高/中/低）

3. **资产方向矩阵**：对每个情景，判断主要资产类别的方向和幅度——
   - 方向：强看多(++) / 看多(+) / 中性(○) / 看空(-) / 强看空(--)
   - 幅度：给出预期波动范围

4. **情景切换信号**：明确从基准情景切换到乐观/悲观情景的触发信号

### 输出模板

```markdown
### 4. 情景推演

#### 情景定义

| 情景   | 概率 | 核心假设 | 触发信号 |
| ------ | ---- | -------- | -------- |
| 基准： | 55%  |          | 当前路径 |
| 乐观： | 20%  |          |          |
| 悲观： | 25%  |          |          |

#### 资产方向矩阵

| 资产类别       | 基准 (55%) | 乐观 (20%) | 悲观 (25%) | 概率加权方向 |
| -------------- | ---------- | ---------- | ---------- | ------------ |
| A股（沪深300） | ○ (±3%)    | ++ (+8%)   | -- (-10%)  | 偏空         |
| 美债10Y        | + (↓15bp)  | ○          | ++ (↓40bp) | 偏多         |
| 美元指数       | + (+1%)    | - (-2%)    | ++ (+3%)   | 偏多         |
| 黄金           | + (+3%)    | ○          | ++ (+8%)   | 偏多         |

#### 情景切换监控

需持续监控以下信号以判断情景切换：

- 切换至乐观：、

```

### 信息收集指引

- `search_paipai` (sources: report, comment)：搜索" 情景分析/市场展望/资产配置"
- `search_paipai` (sources: foreign_report)：搜索 "scenario analysis / asset allocation outlook"
- `search_edb` / `search_global_data`：获取当前隐含波动率、期限结构等市场定价信息；国内宏观用 `search_edb`、国内指数点位用 `delegate_to_agent(agent_type="data_analyst", ...)`，海外资产优先用 `search_global_data`

### 质量检查

- 情景数量 2–3 个，覆盖基准+尾部
- 概率之和 = 100%
- 每个情景有明确的变量假设
- 资产方向矩阵覆盖主要资产类别（≥4类）
- 已定义情景切换信号

## 步骤 5：交易表达方式 (Trade Expression)

### 目标

将情景判断转化为**可执行的交易组合**，包含标的、方向、仓位、对冲和时间框架。

### 执行方法

1. **核心交易**（Core Trade）：基于基准情景的主方向头寸
   - 选择流动性最好、表达最纯粹的标的
   - 明确入场条件/价位、目标价位、持有期

2. **卫星交易**（Satellite Trade）：基于尾部情景的期权/衍生品保护
   - 用低成本方式表达尾部风险（如买入虚值 Put）
   - 或用价差组合降低对冲成本

3. **对冲结构**（Hedge）：降低核心交易的特定风险敞口
   - 识别核心交易的最大风险因子
   - 选择相关性高但成本低的对冲工具

4. **仓位管理**：
   - 基于情景概率和赔率设定仓位比例
   - 单一交易不超过组合的 X%（根据波动率调整）
   - 明确加仓/减仓的触发条件

### 标的选择优先级

| 优先级 | 工具类型       | 适用场景             |
| ------ | -------------- | -------------------- |
| 1      | ETF / 指数期货 | 方向性观点、高流动性 |
| 2      | 个股 / 行业ETF | 结构性观点、Alpha    |
| 3      | 期权策略       | 尾部保护、波动率交易 |
| 4      | 跨资产组合     | 宏观对冲、相对价值   |

```markdown
| 尾部对冲 | 买Put |      | 5%       | 立即     | 保护 | 归零 | 到期   |
| 卫星     | 做多  |      | 15%      |          | +X%  | -Y%  | 1月    |
```

### 信息收集指引

- `search_paipai` (sources: report, comment)：搜索" 交易策略/配置建议/推荐组合"
- `search_paipai` (sources: foreign_report)：搜索 "trade ideas / positioning / portfolio strategy"
- `search_edb` / `search_global_data` / `delegate_to_agent(data_analyst)`：获取候选标的的流动性、波动率、估值数据；境内指数标的走 `指数相关` 数据域，A股个股流动性/波动率/估值走 `个股相关` 数据域，港股/美股等海外标的优先用 `search_global_data`。不同数据域分别 查询 后在分析层合并，禁止直接拼接

### 质量检查

- 交易组合包含核心+对冲，非单边裸露
- 每笔交易有明确的入场条件和止损
- 标的具体到代码/合约级别
- 已计算风险收益比
- 仓位比例合理（单笔不超过组合 50%）

## 步骤 6：失效条件 (Invalidation Conditions)

### 目标

明确列出使整个分析框架失效的 **3–5个** 可观测信号，附带具体的止损/退出规则和应急预案。

### 执行方法

1. **反向思考**：逐一检验步骤1–5中的核心假设——
   - "如果 不成立，整个逻辑链是否崩塌？"
   - "什么信号能最早告诉我假设错了？"

2. **失效信号分类**：

| 类型         | 说明                       | 示例                       |
| ------------ | -------------------------- | -------------------------- |
| **数据失效** | 关键变量读数与假设方向相反 | CPI 连续2月超预期          |
| **政策失效** | 政策响应与预期不同         | 央行意外鹰派/鸽派          |
| **市场失效** | 价格行为与逻辑不符         | 利空出尽后不跌反涨         |
| **结构失效** | 市场微观结构发生质变       | 流动性枯竭、相关性崩塌     |
| **黑天鹅**   | 完全超出框架的新冲击       | 新的地缘事件、金融机构暴雷 |

3. **量化阈值**：每个失效条件必须有可量化的触发标准
   - 不说"如果经济大幅恶化"，而说"如果 PMI 连续2个月 < 48"
   - 不说"如果市场大跌"，而说"如果沪深300 自高点回撤 > 15%"

4. **应急预案**：每个失效条件对应的操作方案——
   - 部分失效 → 减仓 / 调整对冲比例
   - 完全失效 → 全部平仓 / 反向操作

### 输出模板

```markdown

#### 失效信号监控表

| #   | 失效条件 | 类型     | 量化阈值 | 监控频率 | 当前状态 | 触发后操作   |
| --- | -------- | -------- | -------- | -------- | -------- | ------------ |
| 1   |          | 数据失效 |          | 日频     | 🟢安全   | 核心仓位减半 |
| 2   |          | 政策失效 |          | 事件驱动 | 🟢安全   | 全部平仓     |
| 3   |          | 市场失效 |          | 日频     | 🟡关注   | 加强对冲     |

#### 止损规则

- **组合级止损**：总亏损达 -X% 时，无条件全部平仓
- **单笔止损**：见步骤5交易表中各笔止损价位
- **时间止损**：若 <span class="ref-node iconfont icon-lianjie" data-type="reference" data-refs="N"></span>个交易日内逻辑未兑现，重新评估并考虑退出

#### 失效后的备选框架

若当前框架失效，最可能的替代情景是 ，届时应转向 。
```

### 信息收集指引

- 主要基于步骤1–5的分析进行反向推导，无需额外大量搜索
- 可用 `search_paipai` (sources: comment) 搜索" 风险/尾部风险/黑天鹅"补充盲点
- 用 `search_edb` / `search_global_data` 确认当前各失效指标的最新读数；国内宏观指标用 `search_edb`、国内指数指标用 `delegate_to_agent(agent_type="data_analyst", ...)`，海外指标优先用 `search_global_data`

### 质量检查

- 失效条件 3–5 个，覆盖不同类型
- 每个条件有量化阈值，非模糊描述

| 事件类型                        | 典型关键变量                                         |
| ------------------------------- | ---------------------------------------------------- |
