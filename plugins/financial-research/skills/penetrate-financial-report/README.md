# 穿透财报分析框架

聚焦财务报表分析，基于华源证券邹佩轩《穿透财报：读懂财报中的逻辑与陷阱》以及《穿透估值：读懂估值中的共识与博弈》的分析框架，适用于财报全面梳理、风险诊断以及具体科目细节追问，支持正式财报以及业绩预告，提供深度报告模式与简易对话模式，A股、港股、美股全部适配，支持多公司对比。

## 核心理念

**我们不是给财报估值，我们是给叙事估值。** 本框架将**叙事定价**与**财报深度验证**深度融合：

1. **叙事先行**：用DCF反算当前股价隐含的终局利润L（天花板高度），判断市场预期的是什么叙事。
2. **三张表深度验证**：对资产负债表、利润表按完整科目逐项列示，**结合行业背景与公司经营情况，对每一项变动进行深度分析**（不局限于数据对比），判断财报是否在兑现/证伪叙事。
3. **交叉印证**：叙事预期 vs 财报现实，偏差即机会或风险。

### A股市场常见的财报阅读错误

> 忽略估值水平，只关注增速的绝对值、边际变化以及是否超预期，试图从这三个维度寻找下一段时间的市场主线。本质是否定市场的有效性，认为市场的定价视野非常短。

### 正确的做法

**先判断当前股价隐含的叙事（终局业绩天花板高度），再看财报是否在兑现或证伪这个叙事，最后对三张表完整科目逐项做结合行业背景的深度分析。** 增速本身不产生超额收益，叙事变化才产生超额收益。

---

**Skill写到了“四阶导”，可以无限追问**，支持三张报表总览以及任意细节拆分，每一步均严格按照“总-分-总”的金字塔结构展开，内置了大量预制逻辑链，根据询问方式即可自动执行相关分析程序，例如：

1、可以首先要求“分析某某公司指定年份财务报表”，初版报告会详细梳理每一个会计科目，遍历式分析，并给出初步结论。

2、之后可以在对话中补充基本面信息，询问是否存在舞弊或财务粉饰可能，将自动执行重点指标交叉检验程序，逐一排除。

3、投资者可以对任一科目或者初步结论展开追问，自动生成专题报告；也支持多家公司之间的财报对比。

4、最后，可以要求生成财报与叙事的匹配度总结，指导投资决策。

---

**常见话术包括**：

1、分析某公司2025年年报及2026年一季报，生成md格式完整报告（或者不生成报告，直接简要回答）。

2、分析某公司（A股+港股+美股全支持）最新业绩预告，并结合管理层指引，寻找亮点以及风险点。

3、公司近期利润端面临原材料成本上升、运费上升、汇率承压等多重利空，为什么利润表表现还很稳健，毛利率同比还是上升的，有没有可能存在重大调节痕迹。

4、公司汇兑损益、投资收益与公允价值等非经营项目扰动开始放大，能否详细展开，生成md格式完整报告。

5、公司2025年年报中的资产负债表讲了一个什么故事，能否支撑估值中隐含的叙事，生成md格式完整报告。

6、某公司2025年年报中出现了重大会计口径重构，是否存在报表粉饰动机。

7、对比A公司与B公司2025年及2026年一季报，聚焦运营效率与未来增长潜力。

8、某公司2025年年报显示继续亏损，而市场此前预期公司会困境反转，实际亏损源是什么，能否详细拆解，同时分析市场预期落空的原因。

## 运行条件

技能中使用的 data_analyst 数据查询能力，或经用户提供且核验的对应数据。
