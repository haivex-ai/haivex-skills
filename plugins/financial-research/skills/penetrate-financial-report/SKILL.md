# 穿透财报分析框架

> **优先要求**：正文前增加一个详细的摘要。
> 在 DCF 反算时，客观列示市场股价隐含的终局业绩预期，不评价预期对错，不给出理论区间与高估/低估决策；本要求优先于下文及模板中的相关表述。

## 核心理念

**我们不是给财报估值，我们是给叙事估值。** 投资在很大程度上，是"许许诺精彩的未来，然后拿走现在的全部"——所谓的"未来"就是终局，只要终局足够精彩，资本市场对过程的容忍度可以非常高。反之，如果终局不够精彩，无论过程多么波澜壮阔，市场都不会给予高估值。

本框架将**叙事定价**与**财报深度验证**深度融合：

1. **叙事先行**：用DCF反算当前股价隐含的终局利润L（天花板高度），判断市场预期的是什么叙事。
2. **三张表深度验证**：对资产负债表、利润表按完整科目逐项列示，**结合行业背景与公司经营情况，对每一项变动进行深度分析**（不局限于数据对比），判断财报是否在兑现/证伪叙事。
3. **交叉印证**：叙事预期 vs 财报现实，偏差即机会或风险。
4. **高信息密度呈现**：优先用结构化文字、Markdown 表格和明确结论承载财务信息，便于检索、引用和逐项核验。

### 纯文字报告原则（正向引导）

根据实际用户反馈，本报告的**纯文字 + Markdown 表格版本信息密度最高、阅读效果最佳**。生成报告时，主动把可能用于图形展示的内容改写为“关键数据表 → 趋势解读 → 财务含义 → 风险提示”，让读者直接看到数字、判断依据与结论，而不是从低信息量插图中二次提取信息。

- 统一使用标题、段落、列表和 Markdown 表格呈现；DCF 敏感性、财务趋势、现金流质量和五维评价均用数据表与文字结论表达。
- 不生成、下载、搜索、引用或嵌入图片、图表、SVG、Mermaid、HTML `<img>` 等视觉内容，也不调用绘图或图片生成工具。
- 不保留图注、图片路径、图片占位符或 Markdown 图片语法。
- 即使用户提出配图要求，也保持本报告的纯文字最佳形态，并说明本 Skill 通过表格和文字提供更高信息密度的分析结果。

### A股常见的财报阅读错误（必须规避）

> 忽略估值水平，只关注增速的绝对值、边际变化以及是否超预期，试图从这三个维度寻找下一段时间的市场主线。

正确做法：**先判断当前股价隐含的叙事（天花板L），再看财报是否在兑现或证伪这个叙事，最后对三张表完整科目逐项做结合行业背景的深度分析。** 增速本身不产生超额收益，叙事变化才产生超额收益。

## 分析工作流（五步法）

### 第一步：反算股价隐含的叙事（天花板L）

调用本 skill 的 `scripts/dcf_implied.py`（自包含，无外部依赖），或手动完成 DCF 反算：

```
python scripts/dcf_implied.py implied --cap {当前市值} --e1 {E1} --e2 {E2} --e3 {E3}
# 可选：--steady-year 2035（默认）/ --base-year 2025
```

**输入**：当前市值（亿元）、未来3年一致预期净利润 E1/E2/E3、折现率三档（8%/10%/12%）、**稳态期年份（默认 2035 年）**。
**模型假设**：前3年（对应基准年后的可见期，如 2026/2027/2028）用一致预期 E1/E2/E3；自 E3 对应年份起匀速增长至**稳态期（默认 2035 年）**到达终局利润 L；**稳态期（2035 年）起 L 永续稳定（g=0）**。匀速增长的年数 = 稳态期年份 − E3 对应年份（默认约 7 年，随基准年自动调整）。
**输出**：三档隐含终局利润L、L/E3倍数、L/E0倍数、匀速增长阶段隐含复合增速。

> **⚠️ 重要提示（醒目标注）**：空间反算（DCF 反算隐含终局利润 L）**引用了未来三年的分析师一致预期净利润（E1/E2/E3）作为关键输入**。分析师一致预期存在**更新滞后性**——可能未及时反映最新的行业景气变化、公司经营拐点或突发事件，导致反算结果偏离真实预期。**故本模块反算的隐含终局利润 L 与叙事类型判断仅供参考，不构成投资建议，使用时须结合最新公开信息交叉验证。**

**叙事判断**（L/E3分级）：

- <0.5：深度下滑叙事
- 0.5-1：下滑叙事
- 1-2：温和增长叙事
- 2-5：较高增长叙事
- 5-10：高增长叙事（存在叙事饱满风险）
- 10：极高增长叙事（透支风险大）

### 第二步：确定财报验证重点 + 锚定行业背景

根据第一步反算出的隐含叙事，确定财报中哪些部分最值得审视，同时锚定行业背景作为后续逐项变动分析的坐标系：

| 隐含叙事类型             | 财报验证重点                     | 关键科目                                            |
| ------------------------ | -------------------------------- | --------------------------------------------------- |
| 高增长叙事（L/E3>5）     | 增长能否持续？收入质量是否真实？ | 营收增速、应收账款周转率、毛利率、经营现金流/净利润 |
| 温和增长叙事（L/E3 1-5） | 盈利能力是否稳定？再投资效率？   | 毛利率、固定资产周转率、ROE、营运资本占比           |
| 下滑叙事（L/E3<1）       | 是否触底？资产质量恶化程度？     | 资产减值、资产负债率、现金流覆盖、商誉              |
| 周期反转叙事             | 库存周期位置？成本曲线位置？     | 存货周转率、毛利率变化、资本开支节奏                |
| 出海叙事                 | 海外收入占比？汇率影响？         | 分地区收入、海外资产、汇兑损益                      |

**行业背景锚定**（在第一部分 1.1 完成，后续每项变动分析引用）：

- 行业景气度：处于周期什么位置（复苏/扩张/见顶/衰退）？
- 竞争格局：集中度变化、价格竞争烈度、新进入者威胁
- 政策环境：产业政策、补贴退坡、环保/安全监管、贸易壁垒
- 技术变革：技术路线迭代、产能过剩/紧缺切换、国产替代节奏
- 上下游：原材料价格走势、下游需求结构变化、渠道库存

### 第三步：资产负债表深度分析（完整科目 + 逐项变动分析）

对最新一期及上一年年末资产负债表，按以下维度逐项排查，**每一项变动必须结合行业背景与公司经营情况分析原因**：

**生产类资产**（固定资产、在建工程、无形资产、商誉、使用权资产）：

- 固定资产周转率变化趋势 → 是否反映产能过剩/利用率不足？结合行业产能周期
- 在建工程是否长期不转固（利息资本化嫌疑）→ 结合公司扩产计划与行业供需
- 商誉占净资产比例（>30%需警惕减值风险）→ 结合被收购方业绩对赌与行业景气
- 无形资产结构（土地使用权 vs 专利 vs 开发支出）→ 结合公司研发投入与技术路线

**营运资本**（应收账款、预付款项、存货、合同资产、应付账款、合同负债）：

- 应收款项周转率与毛利率是否背离 → 结合行业账期惯例与公司客户结构
- 营运净资产（不含存货）/总资产趋势 → 结合产业链话语权与竞争格局
- 存货周转变化（存货异常堆积=滞销或虚增）→ 结合行业库存周期与渠道库存
- 合同负债 vs 预收账款变化（订单景气度信号）→ 结合下游需求与公司订单能见度

**金融类资产**（交易性金融资产、长期股权投资、其他权益工具投资）：

- 金融资产占比是否过高（脱实向虚）→ 结合公司战略与闲置资金用途
- 长期股权投资收益 vs 投资现金流（关联方输血嫌疑）→ 结合参股公司经营
- 公允价值变动损益占比（利润稳定性）→ 结合金融资产标的性质

**负债与权益**（短期借款、长期借款、应付债券、递延所得税）：

- 有息负债率变化趋势 → 结合融资环境与公司资本开支计划
- 短期借款 vs 货币资金（短债长投风险）→ 结合债务到期结构
- 递延所得税资产/负债变化（利润调节信号）→ 结合可抵扣暂时性差异来源

### 第四步：利润表关键科目拆解（完整科目 + 逐项变动分析）

按重构后的利润表架构拆解，**每一项变动必须结合行业背景与公司经营情况分析原因**：

```
营业总收入
  - 营业总成本（营业成本 + 税金及附加 + 三费 + 财务费用）
  = 营业利润（经营性）
  + 其他收益（政府补助等）
  + 投资净收益（对联营合营企业 + 金融资产）
  ± 公允价值变动 / 减值损失 / 资产处置收益
  = 营业利润（合计）
  ± 营业外收支
  = 利润总额
  - 所得税
  - 少数股东损益
  = 归母净利润
```

**重点拆解维度**（每个维度结合行业背景深度分析）：

1. **收入质量**：营业收入 vs 销售商品收到现金（收现比）；营收增速 vs 应收增速；分产品/分地区收入拆解；量价拆解
2. **成本结构**：毛利率变化归因（量/价/成本结构）；三费率变化趋势；结合原材料价格与产品定价权
3. **非经常性损益**：政府补助、投资收益、公允价值变动占比（>30%需扣非看）；结合产业政策与参股公司经营
4. **减值损失**：资产减值 + 信用减值占利润比例（大幅波动=利润调节嫌疑）；结合行业景气与减值方法论
5. **所得税有效税率**：与法定税率偏离原因（递延税、税收优惠、海外税差）；结合高新认定与税收优惠明细
6. **扣非净利润与 EPS**：扣非占比、股本稀释原因；结合股权激励与回购

### 第五步：生成最终报告

最终 Markdown 报告应基于已读取的数据自行分析并写作。写作前：

1. 读取实际生成且报告依赖的财务数据包、数据备忘和核验清单。
2. 核对报告期、单位、科目合计和缺失值；推算值必须与披露值明确区分。
3. 使用 `write_file` 写入 `tmp/{session_id}/outputs/{company_name}_穿透财报分析报告.md`；长报告分段写入时，首次使用 `mode="overwrite"`，后续使用 `mode="append"` 并传入上一结果的最新 `file_hash`。完成后按本 Skill 框架逐项自检。

#### 第一部分　叙事先行——反算股价隐含预期（约 3 页）

##### 1.1 公司概况与行业背景

- **公司概况**（一段话）：成立年份、上市时间与板块、主营业务、行业地位（市占率/排名等关键事实）。
- **行业背景**（一段话，作为后续变动分析的锚点）：行业当前所处周期位置、竞争格局（集中度/价格竞争）、政策环境、技术变革、上下游供需。**此段为第二、三部分每项变动分析的行业坐标系，必须具体到可量化指标**（如行业产能利用率、原材料价格涨跌幅、下游增速等）。
- 配 **7×4 概况表**（项目|内容|项目|内容），字段：公司简称、股票代码、一级行业、上市年份、当前股价、总股本、当前市值、{最新年度}营收（含增速）、核心市占率×2、{最新年度}归母净利润（含增速）、{最新年度}ROE。

##### 1.2 DCF 反算隐含终局利润 L

> **⚠️ 重要提示（本节开篇必须以醒目方式（加粗/高亮块）置顶写入报告）**：本节的**空间反算（DCF 反算隐含终局利润 L）引用了未来三年的分析师一致预期净利润（E1/E2/E3）作为关键输入**，而分析师一致预期存在**更新滞后性**（可能未及时反映最新行业景气、公司经营拐点或突发事件），**因此反算结果仅供参考，不构成投资建议，使用时须结合最新公开信息交叉验证。**

- 一段话说明模型：基于 DCF 第一性原理，用当前市值 + 前 3 年一致预期净利润反推股价隐含的终局利润 L。**模型假设固定**：前 3 年用一致预期 E1/E2/E3（对应基准年后可见期，如 2026/2027/2028）；自 E3 对应年份匀速增长至**稳态期（默认 2035 年）**到达终局利润 L；**稳态期（2035 年）起永续稳定（g=0）**。匀速增长年数 = 稳态期年份 − E3 对应年份（默认约 7 年，随基准年自动调整）。折现率取 8%/10%/12% 三档。
- 配 **DCF 敏感性表（4×5）**，列：折现率 r | 隐含终局利润 L（亿元） | L/E3 倍数 | L/E0 倍数 | 匀速增长阶段（E3→稳态期2035）隐含复合增速 g。三行对应：
    - 8%（低协方差红利资产）
    - 10%（默认中性）
    - 12%（高风险/流动性折价）
- **强制**：表格必须同时列举 L/E3 与 L/E0 两套倍数。

##### 1.3 叙事类型判断与产业空间对照

- 以中性 r=10% 为基准，给出 L/E3 与 L/E0 两个倍数并解读。
- **L/E3 叙事分级**：<0.5 深度下滑；0.5-1 下滑；1-2 温和增长；2-5 较高增长；5-10 高增长（较饱满）；>10 极高增长（透支风险大）。
- 结合市场对可见期（如 2026-2028）净利润的预期，判断估值由近期业绩兑现还是远期叙事驱动。
- 产业空间测算：给出终局净利润区间，与 DCF 反算 L 比对，判断高估/低估/合理，落一句「估值与产业空间匹配/不匹配」。

##### 1.4 财报验证重点

- 配 **6×4 表**（验证维度 | 关键科目 | 验证逻辑 | {公司}关注点），5 行维度：增长可持续性（营收增速、合同负债）、收入质量（应收周转率、毛利率）、再投资效率（固定资产周转率）、现金流质量（经营CF/总资产）、产业链地位（营运资本占比）。关注点列填该公司具体数字。

#### 第二部分　资产负债表深度分析（完整科目 + 逐项变动分析）（约 9-10 页）

> **开篇说明**：对 {上上年末}、{上年末}、{最新Q1}（标注具体日期，如 2026年3月31日）三个时点，按完整科目逐项列示。列示 {上年末} 较 {上上年末} 的净增加值及增长率，以及 {最新Q1} 较 {上年末} 的净增加值及增长率。**变动 > 20% 的科目标红。**
>
> **核心要求（HARD RULES）**：每个子节的每个科目变动必须配套四要素深度分析——
> ① **变动幅度与方向**：具体数字 + 增长率（标注时间期限，如「从 2024 年末的 2,643 亿增至 2025 年末的 3,308 亿（+25.2%）」）；
> ② **变动原因**：结合行业背景（行业产能/价格/政策/技术）+ 公司经营情况（扩产/收缩/并购/客户结构变化）；
> ③ **同业/历史对比**：与行业均值或公司历史水平对比，判断是否异常；
> ④ **财务质量影响与风险提示**：对盈利能力/资产质量/现金流/偿债能力的影响，及潜在风险。
>
> **每条分析 ≥ 150 字**，禁止「只列数据不分析」。

每个子节结构固定为：**8 列完整科目表 → 「注：变动>20%标红。单位：亿元。」→ 空行 → 「{类别}分析：」→ 编号分析条目（①②③…，每条须标注具体时间期限，每条 ≥150 字，含四要素）。**

8 列表头固定：`科目 | {上上年末} | {上年末} | 净增 | 增长率 | {最新Q1} | 净增 | 增长率`

##### 2.1 流动资产深度分析（约 13 个科目 + 合计）

- 科目：货币资金、交易性金融资产、衍生金融资产、应收票据、应收账款、应收款项融资、预付款项、其他应收款、存货、合同资产、一年内到期的非流动资产、其他流动资产、流动资产合计。
- **逐项分析要求**（每个科目 ≥150 字，含四要素）：
    - **货币资金**：与利息收入勾稽（货币资金×存款利率≈利息收入）；结合公司融资节奏与资本开支计划，判断资金是冗余还是紧张；与行业同期融资环境对比。
    - **交易性金融资产/衍生金融资产**：理财/结构性存款结构，结合公司闲置资金管理策略与利率环境；衍生品是否为套保（结合外币敞口与原材料套保）。
    - **应收票据**：银承 vs 商承结构（银承≈准现金），结合行业结算惯例与公司客户信用。
    - **应收账款**：增速 vs 营收增速（应收增速持续>营收增速=放账换收入）；账龄结构变化；结合行业账期惯例与公司客户结构变化（大客户集中度）。
    - **应收款项融资**：结构优化（银承贴现）vs 真实应收；结合公司票据管理策略。
    - **预付款项**：对上游预付=弱势，预付给关联方=资金占用嫌疑；结合原材料采购模式与供应商关系。
    - **其他应收款**：押金保证金/代垫款/关联方往来，结合业务模式；异常增长需排查。
    - **存货**：周转率变化（异常堆积=滞销或虚增）；原材料/在产品/产成品结构变化，结合行业库存周期与渠道库存；存货跌价准备计提是否充分。
    - **合同资产**：与应收账款的区别（附条件收款权），季度波动结合项目验收节奏；结合公司收入确认政策。
    - **一年内到期的非流动资产/其他流动资产**：结构变化，结合公司资产配置。

##### 2.2 非流动资产深度分析（约 13 个科目 + 合计）

- 科目：长期股权投资、其他权益工具投资、其他非流动金融资产、投资性房地产、固定资产、在建工程、使用权资产、无形资产、商誉、长期待摊费用、递延所得税资产、其他非流动资产、非流动资产合计。
- **逐项分析要求**（每个科目 ≥150 字，含四要素）：
    - **长期股权投资**：参股上游/下游/同业，结合产业链一体化战略；权益法投资收益 vs 投资现金流（关联方输血嫌疑）；被投资方经营情况。
    - **其他权益工具投资/其他非流动金融资产**：公允价值变动进其他综合收益（不影响利润）vs 进损益；结合公司产业布局与财务投资策略。
    - **投资性房地产**：公允价值 vs 成本模式；占比过高=脱实向虚。
    - **固定资产**：产能扩张节奏（结合在建工程转固）；折旧政策变化；固定资产周转率 → 结合行业产能周期与利用率；减值测试。
    - **在建工程**：长期不转固=利息资本化嫌疑；结合公司扩产计划与行业供需（产能过剩行业慎扩产）；转固进度与投产节奏。
    - **使用权资产**：租赁准则影响，结合门店/办公/设备租赁规模。
    - **无形资产**：土地使用权 vs 专利 vs 开发支出结构；摊销期限合理性；结合公司研发投入与技术路线迭代。
    - **商誉**：占净资产比例（>30% 警惕减值）；被收购方业绩对赌完成情况；结合行业景气判断减值风险；商誉减值测试假设（折现率/永续增长率）。
    - **长期待摊费用**：本质是已发生费用的资本化，越大越可疑；结合租赁装修/搬迁补偿等。
    - **递延所得税资产**：可抵扣暂时性差异来源（亏损/减值/薪酬）；结合公司未来盈利预期判断可实现性。
    - **其他非流动资产**：预付工程款/设备款，结合在建工程与扩产计划。

##### 2.3 流动负债深度分析（约 11 个科目 + 合计）

- 科目：短期借款、衍生金融负债、应付票据、应付账款、合同负债、应付职工薪酬、应交税费、其他应付款、一年内到期的非流动负债、其他流动负债、流动负债合计。
- **逐项分析要求**（每个科目 ≥150 字，含四要素）：
    - **短期借款**：规模 vs 货币资金（短债长投风险）；融资成本变化；结合融资环境与公司信用。
    - **衍生金融负债**：与衍生金融资产对应，套保策略。
    - **应付票据/应付账款**：应付账款+应付票据 vs 应收（差额=产业链话语权）；银承 vs 商承结构；结合行业账期惯例与公司供应商关系。
    - **合同负债**：预收性质，订单景气度先行指标；结合下游需求与公司订单能见度；同比/环比变化解读。
    - **应付职工薪酬**：结合人员扩张/收缩与薪酬政策；股权激励计提。
    - **应交税费**：与利润总额匹配，结合增值税/所得税缴纳节奏。
    - **其他应付款**：押金保证金/代收款/关联方往来；异常增长需排查。
    - **一年内到期的非流动负债**：长期借款/债券转入，结合债务到期结构与再融资计划。
    - **其他流动负债**：待转销项税/短期理财，结合业务模式。

##### 2.4 非流动负债深度分析（约 9 个科目 + 合计）

- 科目：长期借款、应付债券、租赁负债、长期应付款、预计负债、递延收益、递延所得税负债、其他非流动负债、非流动负债合计。
- **逐项分析要求**（每个科目 ≥150 字，含四要素）：
    - **长期借款**：规模变化，结合资本开支计划与融资环境；融资成本；抵押/信用借款结构。
    - **应付债券**：可转债/公司债，骤增需关注用途；转股进度（可转债）；结合利率环境。
    - **租赁负债**：与使用权资产对应，结合租赁规模。
    - **长期应付款**：融资租赁/专项应付款，结合业务模式。
    - **预计负债**：质保/售后准备金/诉讼，与出货量勾稽；结合行业质量风险。
    - **递延收益**：政府补助递延，结合产业政策与公司补贴依赖度。
    - **递延所得税负债**：应纳税暂时性差异，结合固定资产折旧差异/公允价值变动。
    - **其他非流动负债**：结合业务模式。

##### 2.5 所有者权益深度分析

- **10×8 权益表**：实收资本（股本）、资本公积、减：库存股、其他综合收益、专项储备、盈余公积、未分配利润、归母所有者权益合计、少数股东权益。
- 紧接 **3×8 负债+权益汇总表**（2 行数据）：负债合计、所有者权益合计。
- **逐项分析要求**（每个科目 ≥150 字，含四要素）：
    - **实收资本（股本）**：增发/回购/转增，结合股权激励与再融资；股本稀释对 EPS 影响。
    - **资本公积**：H股/股权激励/定增溢价，结合公司融资历史。
    - **库存股**：回购规模与用途（注销/股权激励），结合估值与资本运作。
    - **其他综合收益**：公允价值变动/外币折算/套期，结合金融资产与海外业务。
    - **专项储备**：安全生产费，结合行业安全风险。
    - **盈余公积**：法定计提，变化小。
    - **未分配利润**：净利润留存-分红，结合分红政策与再投资需求；与净利润勾稽（期初+净利润-分红=期末）。
    - **少数股东权益**：战投/合资，结合子公司股权结构与并表范围。
- **资产负债率 + 带息负债占总资产比**：判断财务杠杆健康度，结合行业可比公司。

#### 纯文字信息展开方式

- **趋势类数据**：用多期数据表列出绝对值、同比/环比变化，并在表后总结方向、拐点与持续性。

- **质量评价**：用“维度｜关键指标｜公司表现｜同业对比｜评级｜理由”表呈现，确保评级可追溯到具体数字。
- **综合结论**：按“事实 → 判断 → 风险 → 后续跟踪指标”组织文字，让每项结论都可验证、可引用。
