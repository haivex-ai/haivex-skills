# 全A样本财务打分与分位数计算使用指南

> **定位说明**：本模块是**可选的、按需触发的独立视角**，**不进入穿透财报的默认报告流程**。
> 仅当用户**显性要求**"全A横向对比 / 分位数定位 / 该公司在全市场处于什么水平 / 财务指标全市场排名"等时，才加载本指南并调用 `scripts/financial_scoring.py`。
> 常规穿透财报分析（默认五部分报告）无需本模块。

> **数据来源**：全部数据来自 **已配置的数据查询工具**（由 Agent 在执行时取数），
> 由脚本在本地计算全A分位数与打分。**无需用户上传任何 Excel，不联网抓取，不涉及任何外部数据品牌。**

---

## 〇、两段式架构（为什么 Agent 取数 + 脚本算分）

skill 内的 Python 脚本运行在**无网络、无平台工具访问权限**的沙箱中，无法自行调用平台数据接口。因此本模块采用两段式：

1. **Agent 取数段**：执行 skill 时，Agent 用 `data_analyst` 取得两类数据并整理为标准 CSV：
  - 全A样本横截面（某报告期，剔除银行/非银金融）
  - 目标公司的一致预期 vs 实际净利润对比
2. **脚本算分段**：`scripts/financial_scoring.py` 读取 CSV，在本地计算全A分位数、五大指标打分、一致预期偏差与异常信号，输出 JSON。

这样保证结果**可复现、可离线运行**，且不把数据源实现细节耦合进脚本。

### 取数原则

向 `data_analyst` 写清样本范围、报告期、指标和业务口径，再整理成下文规定的标准 CSV。报告期和单位必须一致，空值不得改成 0。

---

## 一、Agent 取数清单与口径（关键）

### 文件1：全A样本横截面 CSV

- **样本范围**：以锁定报告期为 as-of 截点，取该时点在市的全部 A 股并使用该时点有效的申万行业版本，**剔除申万一级行业为“银行”“非银金融”的公司**。禁止用运行日存续状态或当前行业分类回填历史报告期，以免产生幸存者偏差和分类穿越。
- **输入内容**：每只证券在锁定报告期保留一行，并注明实际样本数、报告期类型、币种和单位。
- **落地表头**（严格用以下中文列名，脚本按同义词模糊匹配；财务科目缺失可留空，但报告期、报告类型、证券、在市状态、行业及版本/生效期、币种、金额单位、值主体、数据版本、有效期不得为空）：
  ```
  报告期,报告类型,股票代码,公司简称,报告期末在市状态,申万一级行业,行业版本,行业生效期,币种,金额单位,值主体,数据版本,有效期,营业收入,营业成本,应收账款,应收款项融资,合同资产,预付款项,应付账款及票据,合同负债,固定资产,无形资产,总资产,经营活动产生的现金流量净额,ROE
  ```
- **字段口径说明**：

  - 报告期、报告类型、股票代码和公司简称用于唯一标识样本；一只证券在该报告期只能一行。
  - 在市状态、申万一级行业及其版本使用锁定报告期的 as-of 口径，不用运行日状态或当前分类回填历史。
  - 营业收入、营业成本及资产负债表/现金流科目使用同一报表口径和量纲；固定资产、无形资产、总资产等取基础主科目。
  - ROE 使用加权平均净资产收益率并注明百分比单位；累计与单季口径不得混用。
  - 未覆盖科目保留为空，不用默认值补齐；同一计算的分子分母必须统一量纲。

  > **空值传播**：脚本不会把缺失科目补成 0。某指标所需的任一组成科目缺失时，该股票对应指标记为缺失，并从该指标的分位数有效样本中排除；真实 0 值仍按 0 参与计算或触发分母保护。

### 文件2：一致预期 vs 实际净利润对比 CSV（可选，用于指标5）

- **输入内容**：每个预测财年只保留一个锁定快照，并注明预测快照日、币种和单位。

- **落地表头**（严格）：
  ```
  股票代码,公司简称,预测快照日,预测财年,一致预期净利润,实际归母净利润,币种,金额单位,值主体,数据版本,有效期
  ```
- **口径**：
  - **一致预期净利润**：对每个预测财年固定取**该财年一月的首个有效快照**，且预测财年=该年。若一月没有有效快照，则该财年记为覆盖缺口并省略，不得改取其他月份、其他财年或多个快照平均。
  - **实际归母净利润**：该财年年报的实际归母净利润（利润表业务对象，归属母公司口径）。
  > **品牌中性**：本指标统一称"**一致预期**"，**不使用任何外部数据品牌名称**。

## 二、五大指标体系（计算口径）

脚本对全A样本每只股票计算下列指标，再算目标公司在全A中的分位数。

### 指标1：应收款项周转率（对数）与毛利率

- **应收款项周转率** = 营业收入 /（应收账款 + 应收款项融资 + 合同资产），取自然对数（消除右偏）。
- **经济含义**：周转率越高→回款能力越强。与毛利率结合看：二者应同向。
- **背离信号**：周转率下降（分位低）+ 毛利率上升（分位高）= 可疑（放账换收入或应收注水）。脚本内置该背离信号检测。
- 典型异常案例：华讯方舟、东方金钰。

### 指标2：（固定资产+无形资产）周转率（对数）

- = 营业收入 /（固定资产 + 无形资产），取自然对数。
- **经济含义**：单位生产性资产创造收入的能力。持续下降→再投资效率恶化/产能过剩/固定资产注水。
- 典型异常案例：抚顺特钢（成本藏进固定资产）。

### 指标3：营运净资本（不含存货）/总资产

- 营运净资本（不含存货）=（应收账款 + 应收款项融资 + 合同资产 + 预付款项）−（应付账款及票据 + 合同负债）。
- = 上式 / 总资产。
- **方向：越低越好**（负值→强势占款，产业链话语权强；正值且高→被上下游占用）。脚本对此指标按"越低越好"解读分位。

### 指标4：经营性现金流量净额 / 总资产

- **经济含义**：利润现金含金量核心指标。持续低于净利润→利润水分大。
- 分位 <20% 触发现金流异常信号。
- **注意**：季度数据有季节性（Q1-Q3 经营现金流通常偏低），若用季度截面须同季对比。

### 指标5：一致预期 vs 实际业绩

- 偏差率 =（实际归母净利润 − 一致预期净利润）/ |一致预期净利润|。
- **解读**：平均绝对偏差 >30% → 预测性差、估值锚不稳；≤10% → 预测性好、商业模式稳定；10%~30% → 中等。
- 反映商业模式的可预测性与业绩稳定性。

## 三、脚本用法

```bash
# 基本用法（含一致预期）
python scripts/financial_scoring.py \
  --company "贵州茅台" \
  --sample "全A样本_2024年报.csv" \
  --consensus "贵州茅台_一致预期对比.csv" \
  --period "2024-12-31" \
  --output "贵州茅台_全A分位.json"

# 不做一致预期（省略 --consensus，指标5跳过）
python scripts/financial_scoring.py \
  --company "贵州茅台" \
  --sample "全A样本_2024年报.csv" \
  --output "贵州茅台_全A分位.json"
```

- `--company`（必填）：须与样本"公司简称"列取值一致；脚本支持唯一模糊匹配。
- `--sample`（必填）：全A样本横截面 CSV。
- `--consensus`（可选）：一致预期对比 CSV。
- `--period` / `--output`（可选）：`--period` 如提供，必须与样本中唯一报告期完全一致；输出 JSON 会记录输入文件校验信息。

## 四、注意事项

1. **样本范围**：已剔除银行与非银金融（报表结构差异大）。若用户要做特定行业内横向分位，可在取数时进一步按申万一级行业过滤。
2. **季度可比性**：若用季度截面，须同季度对比（Q1比Q1），不可跨季比较。
3. **分位数方向**：指标3"越低越好"，其余"越高越好"；脚本已内置方向解读，勿反向理解。
4. **对数变换**：周转率类指标取自然对数后计算分位；若周转率≤0（分母为0或负），该股该指标记为缺失，不参与分位。
6. **港股公司**：本模块为 A 股样本；港股公司可参考 A 股同行业分位，但须说明口径差异。
7. **不进默认报告**：本模块结论仅在用户显性要求时，作为穿透财报报告的**附加视角**补充，不改变默认五部分报告结构。
8. **输入固定**：标准 CSV 生成后不得切换报告期或快照；报告与脚本输出必须引用同一份输入文件。
