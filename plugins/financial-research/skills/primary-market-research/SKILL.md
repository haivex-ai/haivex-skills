# 一级市场案头研究

把公司研究、访谈准备、融资跟踪和赛道研究统一到一套可追溯工作流。先选择模式，再取得所需结构化数据，最后交付一份主 Markdown。

如果用户只要结构化明细、列表、计数或简单汇总，不生成研究判断和报告，改用 `primary-market-data`；本 skill 不抢占纯查数任务。

## 先选择模式

| 用户意图 | 模式 | 读取参考 |
| --- | --- | --- |
| 项目扫描、BP 速览、快速看看、投资价值速判 | 公司速览 | `references/company-due-diligence.md` |
| 尽调、商业尽调、完整 CDD、深度尽调 | 深度 CDD | `references/company-due-diligence.md` |
| VC、PE、母基金、S 基金画像 | 投资机构画像 | `references/company-due-diligence.md` |
| 访谈提纲、专家访谈、客户访谈、管理层访谈 | 访谈提纲 | `references/interview-guide.md` |
| 融资日报、融资周报、创投动态、融资扫描 | 融资快报 | `references/funding-brief.md` |
| 未上市玩家、赛道全景、竞争格局、赛道深度 | 赛道研究 | `references/sector-landscape.md` |

只给公司名且无法判断轻重时，问用户要“快速速览”还是“完整 CDD”。“做尽调”默认深度 CDD；只有明确说快速、速览、扫描时才走公司速览。

## 结构化数据原则

任何一级市场结构化查询都必须先读取 `references/data-routing.md`，并遵守以下顺序：

1. 向 `data_analyst` 写清业务对象、时间范围、实体、口径和期望输出。
2. 公司任务先确认唯一主体，再查询融资、竞品和产品；融资快报从事件维度查询指定自然日窗口，再补命中公司画像。
3. 只使用有效且允许披露的记录，结果保留数据日期、币种、单位、约数和缺失项。
4. 数据缺失或查询失败时停止猜测并说明缺口；公开资料可以补充，但不能伪装成结构化数据。

## 通用工作流

1. **锁定任务**：确认模式、实体或赛道、自然日时间窗、地域、轮次、输出深度和可选交付格式。
2. **结构化打底**：按上述原则委托 DA，取得当前任务需要的结构化事实。
3. **多源补齐**：读取 `references/evidence-and-sourcing.md`。结构化库负责公司画像、融资、竞品、机构和组织关系；官网、监管或司法来源、行业协会、公告、研报、纪要和公开网页补团队、客户、市场规模、政策、法律风险和最新变化。
4. **交叉核验**：关键融资额、估值、市场规模和主体身份尽量两源核验；来源冲突时保留差异，不擅自抹平。
5. **形成判断**：每个重要事实后写投资含义、风险或待验证假设，不只做资料堆砌。
6. **生成交付**：读取必要证据后完成分析，并用 `write_file` 生成一份主 Markdown。材料较多时按主题分批读取，不要把未核验的摘要当作事实。

## DA 委托模板

下面模板只描述业务语义，必须保持这种抽象层级：

```python
delegate_to_agent(
    agent_type="data_analyst",
    instruction=(
        "目标公司为「{company_name}」。若主体存在歧义，先返回候选供确认。"
        "确认后分别查询：①公司画像；②完整融资历史；"
        "③竞品与相关公司；④产品信息。"
        "只取有效且允许披露的记录；金额注明币种、单位和是否约数，缺失项明确标注。"
    )
)
```

融资快报应改写为“指定自然日窗口内的一级市场股权融资事件 + 命中公司画像”，赛道全景应改写为“按赛道关键词召回未上市公司 + 最新融资 + 竞品/相关公司扩展”。不要把示例中的任务范围机械复制到其它模式。

## 空结果和失败处理

1. 先确认公司全称、赛道同义词、日期窗口和轮次条件。
2. 调整业务描述后重试一至两次。
3. 确认无数据时说明“当前数据在该口径下未返回记录”；查询失败则如实说明失败，不把两者混为一谈。
4. 可用 `search_paipai`、`doc_searcher`、`search_web` 补公开资料，但必须标明来源类型，不能替代或伪装成结构化数据。
5. 不得使用模拟数据填空。

## 输出纪律

- 最终报告不出现内部数据管线或维护信息。
- 结构化来源统一面向用户写为“一级市场数据”；公开来源按真实机构或链接标注。
- 金额换算为易读单位并注明币种；约数保持约数，不伪造精确值。
- 一级市场估值与上市公司市值、PE、PB 不是同一口径，不直接混比。
- 公司主体名和成立时间需与最新公开报道核验；主体变化时说明旧主体与当前运营或融资主体的关系。
- 结构图使用带 `mermaid` 语言标记的代码块；数据图使用 `plot`。不要手写签名图片 URL。
- Word、PPT、定时和推送仅在用户明确要求时追加。
