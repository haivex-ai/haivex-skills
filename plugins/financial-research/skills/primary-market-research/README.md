# 一级市场研究

面向 PE/VC 场景的公开案头研究技能，将公司研究、访谈准备、融资跟踪和赛道研究统一到一套可追溯工作流，输出带投资判断的结构化研究报告。

## 适用场景

- 非上市公司项目速览、BP 扫描、投资价值快速判断
- 完整商业尽调（CDD）：业务、财务、团队、竞争、风险全景分析
- 投资机构画像：VC、PE、母基金、S 基金的投资偏好与组合分析
- 生成管理层、行业专家、客户或供应商访谈提纲
- 创投融资日报 / 周报、增量融资动态跟踪
- 赛道玩家全景、竞争格局梳理与赛道深度报告

## 研究模式

| 用户意图                     | 模式         |
| ---------------------------- | ------------ |
| 项目扫描、BP 速览、快速看看  | 公司速览     |
| 尽调、商业尽调、完整 CDD     | 深度 CDD     |
| VC、PE、母基金、S 基金画像   | 投资机构画像 |
| 访谈提纲、专家访谈、客户访谈 | 访谈提纲     |
| 融资日报、融资周报、创投动态 | 融资快报     |
| 赛道全景、竞争格局、赛道深度 | 赛道研究     |

只给公司名且无法判断轻重时，会先确认要「快速速览」还是「完整 CDD」。

## 输入

| 字段     | 是否必填 | 说明                               |
| -------- | -------- | ---------------------------------- |
| 研究对象 | 必填     | 公司名、机构名或赛道关键词         |
| 模式     | 选填     | 见上表（默认按用户表述自动判断）   |
| 时间范围 | 模式相关 | 融资快报类需指定自然日窗口         |
| 关注焦点 | 选填     | 如"重点看技术壁垒"、"聚焦出海进展" |

## 输出

一份主 Markdown 研究报告，特点是：

- **结构化打底**：公司画像、融资历史、竞品、机构等事实来自一级市场结构化数据
- **多源补齐**：团队、客户、市场规模、政策、法律风险等由官网、监管、行业协会、研报、公开新闻补充，逐项标注来源
- **交叉核验**：关键融资额、估值、市场规模两源核验；来源冲突时保留差异并说明
- **研究判断**：每个重要事实后给出投资含义、风险或待验证假设，不做资料堆砌

## 说明

- 本技能面向 **研究交付**
- 报告中不暴露内部数据实现细节；结构化来源统一标注为「一级市场数据」，公开来源按真实机构或链接标注
- 金额为约数时保持约数口径，不伪造精确值；一级市场估值与上市公司估值口径不直接混比
- 正式数据查询为空时如实说明缺口，不用模拟数据或网页结果伪装填充

## 运行条件

data_analyst、doc_searcher、search_paipai 及相应宏观、全球数据和专利/论文检索能力；纯查数转交的 primary-market-data 不在此包内。
