# DSZ 商品整理

将商品链接或已有商品资料整理成符合 DSZ 模板的上架文件，方便检查和后续导入。

## 适合做什么

- 整理商品标题、中英文描述和各个 SKU 的规格。
- 准备与商品规格对应的主图和详情图。
- 按 DSZ 模板整理上架表，计算资料齐全的商品价格和区域运费。

## 需要提供什么

提供商品链接或已采集的商品资料，说明要处理的商品和结果保存位置。已有 SKU 台账或特殊的图片、定价要求也可以一起提供。

## 会得到什么

商品上架表、图片、中英文商品文案、SKU 台账和交付说明。缺少价格、图片或其他资料时，会在结果中标明缺项。

当前交付保存在本地；商品发布和 ERP 修改需要另行安排。
