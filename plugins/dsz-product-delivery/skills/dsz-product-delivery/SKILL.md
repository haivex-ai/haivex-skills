# DSZ 商品整理

按用户提供的商品资料完成下面六步，结果保存到指定位置。使用当前可用的妙手、Image Agent 和文档/表格工具直接处理。

随包模板位于 `templates/`：
- `import_products_template上架.xlsx`：复制后填表，保留原表头和列顺序。
- `import_products_categories（类目）.xlsx`：查找类目编号。
- `定价02.xlsx`：计算售价和区域运费。
- `物流售后.html`：追加到商品英文描述末尾。

基本要求：不编造参数、条码、价格或图片链接；不把不同规格的文案和图片放错；缺什么就如实说明，继续完成能做的部分。不要覆盖用户已有的文件。

## 1. 读取商品

通过妙手查找已有采集记录，没有则采集用户给出的链接。读取商品标题、属性、全部 SKU、各规格采购价、包装尺寸和重量，以及主图、详情图。

电器按澳洲站点筛选插头规格，排除明确不适用的国标、美规、欧规等款式。USB 等不涉及插头差异的规格正常保留。清理规格名称中的备注，保留真实的颜色、尺寸和功能差异。

## 2. 整理标题和描述

删除品牌、跨境、批发、定制、证书认证、产地、电商平台名称及欧式、美式等地区风格宣传；图片中的文字也按此处理。避免夸大、绝对化和无依据的功效描述。

用自然的澳式英语重写标题，将商品名称与对应规格组合，控制在 60 字符内。根据商品文字和图片整理中英文描述，按“标题、简介、产品亮点、规格、包装内容、适用人群、使用场景”分层，短句分点。没有依据的内容不补写。

读取图中参数时，结合标注线、对应部位和单位确认含义；看不清的就留待确认。

英文描述转成 HTML，末尾附上 `物流售后.html`，填入 Description；中文对照另存供查看。共用内容可以复用，有规格差异的地方分别写清楚。

## 3. 处理图片

每个 SKU 准备对应主图，加 4 张详情图，均为 1:1。详情图可以共用，共用前确认图中的外观、功能和使用效果适用于对应规格。

- 主图干净且规格正确时直接使用，必要时调整比例；有杂乱文字时用 Image Agent 清理，或基于原图制作白底图，可加简短英文规格标题。
- 详情图优先修改来源素材：翻译中文、删除上述宣传文字、调整为方形；可选产品细节、参数和使用场景等不同内容。
- 保持商品外观、结构和功能真实，文字清楚，不用重复图凑数。某张图只适合部分规格，就用于那些规格。
- 可以调整场景和排版，但不要补画来源未展示、无法确认的内部结构或配件。

处理后的图片保存到本地。Images 按主图在前的顺序，用英文逗号分隔对应成品的有效公网链接。当前暂不上传新图：能用的原图链接正常填写，新图保留本地并说明待补链接；主图没有链接时先将 Images 留空。确实补不足 5 张时说明缺口。

## 4. 填写上架表

每个保留 SKU 一行，按下面规则填写：

| 字段 | 填写方式 |
|---|---|
| SKU | `XM-LB001-ZD01`。LB 序号跨商品连续递增，ZD 是商品组号；第二个商品使用 ZD02。已有台账则接续，没有则从 LB001/ZD01 开始，并说明尚未核对历史编号。 |
| SKU Title | 对应规格的英文标题。 |
| Parent SKU | 每行分别为 `XM-ZD01-01`、`XM-ZD01-02` 等。 |
| Parent SKU Title | 同组统一为 `XM ZD01`。 |
| Option1/2 Name、Value | 填两组实际属性名和值，如 Colour / Black、Style / Remote Control。 |
| EAN Code | 有真实条码就填，没有留空，不随机造码。 |
| Status、Stock | 分别填 1、100。 |
| Brand Name | 留空。 |
| Colour、包装字段 | 有资料就按表头单位填写；重量 kg、三边 cm，CBM 为三边乘积除以 1000000。缺失留空。 |
| Sub-subcategory | 从随包类目表选最合适的实际编号。 |
| Description、Images | 填前面准备好的英文 HTML 和对应图片链接。 |

## 5. 计算价格和运费

读取妙手返回的包装尺寸、重量与逐 SKU 采购价，在 `定价02.xlsx` 的副本中计算。尺寸或重量拿不到就留空，跳过受影响 SKU 的定价，文件名标注“无价格”，不用为补数据反复查找。

按商品选择不带电、带电或特货区域。不带电和带电的尺寸上限为 59×49×39 cm，超出按特货；实际重量和体积重按定价表说明处理，注意表中重量输入单位为克。

- **包邮**（默认）：按原文示例取对应区域最下面一档区域定价的第一列，常规货为四区、特货为三区，再取表内 10% 折扣前的售价，填 Price (Incl. GST)。RRP (Incl. GST) = 售价 × 2；AU 各区域运费填 0，NZ 填 5。
- **买家承担运费**：取表中“买家承担运费”对应档的售价，将各区域运费复制到上架表对应列；RRP = 售价 × 3.5。特货表注明不走买家承担运费时，向用户确认运费方式。
- 用户指定利润档位时按其要求选择。各 SKU 的采购价、包装或重量不同，要分别重算；不要抄模板里的示例价格。

## 6. 检查并交付

打开生成的表格和图片，对照来源检查 SKU 有没有漏掉或放错、文案和图片是否对应、价格和单位是否正确、图片文字是否清楚。发现问题就修改；没完成的部分如实说明。

保存到用户指定目录：
- `XM-ZD01.xlsx`：按实际商品组号命名；缺价格或图片时加 `-无价格`、`-图片待补` 等说明。
- `图片/`：最终采用的图片。
- `SKU台账.csv`：保存 SKU、原始规格、货源链接、源头价格和对应图片文件，方便接续编号和查货源。
- `商品文案.txt`：中英文商品描述对照。
- `交付说明.txt`：简要列出结果、缺项及受影响 SKU；没有完成的步骤不要写成已完成。

当前只生成本地交付，不发布商品、不修改 ERP；原文中的 ERP 备注先记入交付说明。

如果用户只要求选品并保存网址和图片，按其关键词、数量及销量/一件起批等筛选条件输出链接、图片和能取得的指标即可，不必执行后续上架流程。
